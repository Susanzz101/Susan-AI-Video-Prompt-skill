# 参考格式深度分析报告

## 一、参考格式的核心特征提取

基于提供的7张参考截图，以下是专业提示词格式的核心要素：

### 1.1 秒级精确时间码
- **现状**：当前使用 `(00:00-00:04)` 4秒为单位
- **参考格式**：使用 `[00:00-00:03]` 3秒或更精细的时间单位
- **改进点**：
  - 时间码用方括号 `[]` 而非圆括号 `()`
  - 每个镜头2-4秒，更精细的节奏控制
  - 关键动作时刻可精确到秒（如 00:02 产品出现）

### 1.2 多层次描述结构（5层金字塔）

参考格式的每个分镜包含以下层次：

```
[时间码], {镜头语言层}
【描述主体层】
  ├─ 动作描述（主动作线）
  ├─ 表情/眼神（情绪线）
  ├─ 产品状态（产品线）
  └─ 环境细节（氛围线）
(音效：音效设计层)
```

**当前问题**：我们的格式是线性描述，没有明确的"层级"概念

**改进方案**：
```
[00:00-00:03], {特写/缓推镜头/景深2.8}
模特右手从画面下方缓缓托起【产品】至胸前位置，手指轻握瓶身中部，产品正面标签完全对准镜头。
眼神从产品移向镜头，嘴角自然上扬带出真诚微笑，眉眼舒展。
【产品】在柔光下呈现玻璃质感，瓶身高光点在右上角，背景虚化成暖黄光斑。
(音效：轻柔托举声+环境底噪+呼吸声)
```

### 1.3 电影级镜头语言词库

#### 景别系统（由远到近）
- **远景**：展示整体环境，人物占画面1/4以下
- **全景**：展示人物全身+周边环境
- **中景**：膝盖以上到头顶
- **半身中景**：腰部以上到头顶
- **近景**：胸部以上到头顶
- **特写**：肩部以上或产品特写
- **大特写**：面部局部或产品细节

#### 运镜方式
**推镜（Push in）**：
- 缓推：营造情绪递进感
- 快推：制造紧张/惊喜
- 示例：`{半身中景→特写/缓推2秒}`

**拉镜（Pull out）**：
- 揭示环境/制造反差
- 示例：`{特写→中景/缓拉3秒}`

**摇镜（Pan）**：
- 横摇：展示产品序列/环境横移
- 竖摇：从人物到产品/从产品到人物
- 示例：`{横摇镜头/从左到右扫过产品}`

**跟镜（Follow）**：
- 跟随人物动作移动
- 示例：`{跟镜/随手部动作移动}`

**固定机位（Static）**：
- 稳定构图，突出动作本身
- 示例：`{固定机位/正面特写}`

**环绕镜头（Orbit）**：
- 围绕产品旋转
- 示例：`{环绕镜头/顺时针180度}`

**俯拍（Top shot）**：
- 从上往下45-90度
- 示例：`{俯拍特写/75度角}`

**仰拍（Low angle）**：
- 从下往上拍摄
- 示例：`{仰拍中景/30度角}`

#### 景深控制
- **浅景深**：`景深f/1.4` `景深f/2.8` - 背景虚化，突出主体
- **深景深**：`景深f/8` `景深f/11` - 前后景清晰
- 示例：`{特写/景深f/2.8/背景虚化成光斑}`

#### 光影描述
- **光位**：顶光/侧光/逆光/顺光/底光
- **光质**：硬光（阴影清晰）/柔光（阴影柔和）
- **光效**：高光点/阴影层次/轮廓光/眼神光
- 示例：`侧面45度柔光打亮面部，鼻梁高光清晰，眼睛有明显眼神光`

#### 构图法则
- **三分法**：`画面按三分线构图，人物眼睛在上三分线`
- **中心构图**：`产品居中占画面60%`
- **对角线构图**：`产品沿对角线从左下到右上排列`
- **留白**：`人物占画面右侧2/3，左侧留白用于字幕区`

#### 切换方式
- **硬切（Cut）**：直接切换
- **卡点硬切**：配合音乐节奏
- **淡入淡出（Fade）**：柔和过渡
- **溶解（Dissolve）**：两个镜头叠化
- **擦除（Wipe）**：一个镜头推开另一个
- 示例：`{卡点硬切至下一镜头/配合鼓点}`

### 1.4 动作描述的"动词精准度"

**当前问题**：我们用"拿起""展示"等笼统动词

**参考格式特征**：动词精准到"怎么拿""拿到哪里""速度如何"

对比：
- ❌ 低精度：`模特拿起产品展示`
- ✅ 高精度：`模特右手从画面下方缓缓托起【产品】至胸前位置，手指轻握瓶身中部避开标签区，停顿0.5秒后轻轻旋转瓶身使标签完全对准镜头`

**动作拆解维度**：
1. **身体部位**：右手/左手/双手/单手食指和拇指
2. **起点→终点**：从画面下方→至胸前位置
3. **速度/节奏**：缓缓/快速/停顿0.5秒/
4. **力度/质感**：轻握/紧握/托起/捏住
5. **空间位置**：瓶身中部/标签区/底部
6. **附加动作**：旋转/倾斜/轻摇

### 1.5 表情/眼神的"情绪线"独立描述

**当前问题**：表情描述混在动作描述中

**参考格式特征**：情绪线单独成句，构成情绪弧光

示例：
```
[00:00-00:03]
模特双手捧起【产品】缓缓举至面前。（动作线）
眼神从低垂看产品，缓缓抬起看向镜头，眉眼间从好奇转为确认，最后嘴角带出"就是它"的微笑。（情绪线）
【产品】在手中占据画面中心，柔光从左侧打亮瓶身。（产品线）
(音效：轻柔托举声)
```

**情绪弧光设计**（单个15秒视频的情绪变化）：
- 沉浸式吃播：期待→咬下的瞬间满足→回味享受→停不下来
- 口播种草：亲切开场→讲解时的真诚→使用时的惊喜→分享时的满足
- 剧情带货：冲突时的紧张→转折时的意外→产品出现的恍然大悟→结尾的爽感

### 1.6 产品状态的"产品线"独立追踪

**参考格式特征**：每个分镜都明确描述产品的状态变化

示例（口播类15秒的产品线）：
- [00:00-00:03]：产品在画面外/包装盒中（制造悬念）
- [00:03-00:06]：产品出现在手中（揭示）
- [00:06-00:10]：产品特写展示正面（卖点可视化）
- [00:10-00:15]：产品使用中/效果展示（转化）

**产品在画面中的6个维度**：
1. **位置**：画面中心/下方1/3/右侧/手中
2. **占比**：占画面30%/50%/70%
3. **角度**：正面/侧面45度/斜上方
4. **状态**：静置/被托举/使用中/打开后
5. **光影**：高光位置/阴影层次/质感表现
6. **与人物关系**：被手握住/被嘴咬住/在眼神注视下

### 1.7 音效设计的"分层叠加"

**当前问题**：音效是平面罗列

**参考格式特征**：音效分层，有主次和空间感

**音效三层结构**：
```
(音效：
  [环境底噪层] 咖啡厅轻微人声嗡嗡+杯碟碰撞远处
  [动作音效层] 瓶盖旋开清脆声+液体倒出声+杯子放下轻响
  [情绪音效层] 满足的轻叹气声
)
```

**沉浸式吃播的音效分层**：
```
(音效：
  [环境层] 车内密闭空间底噪+车窗外隐约街市声
  [食物层] 包子皮撕开柔软声+酱汁流动湿润声+咬合咀嚼声
  [人物层] 轻微吸口水声+满足的"嗯——"轻哼声
)
```

## 二、当前skill与参考格式的差距总结

### 2.1 格式层面
| 维度 | 当前格式 | 参考格式 | 改进方向 |
|---|---|---|---|
| 时间码符号 | `()` 圆括号 | `[]` 方括号 | 统一使用方括号 |
| 时间粒度 | 4秒一段 | 2-3秒一段 | 更精细的节奏控制 |
| 描述结构 | 线性长句 | 分层短句 | 拆分成动作/情绪/产品/音效四层 |
| 镜头标注 | `{半身中景/固定机位}` | `{特写/缓推/景深2.8}` | 增加运镜+景深+光影 |

### 2.2 语言层面
| 维度 | 当前水平 | 参考水平 | 改进方向 |
|---|---|---|---|
| 动词精准度 | "拿起""展示" | "右手从画面下方缓缓托起至胸前" | 补充动作拆解6维度词库 |
| 镜头语言 | 基础景别 | 推拉摇移+景深+光影+构图 | 补充电影级镜头词库 |
| 情绪描述 | 混在动作中 | 独立的情绪线 | 拆分情绪线，设计情绪弧光 |
| 产品追踪 | 零散提及 | 每镜必有的产品线 | 建立产品状态追踪表 |
| 音效设计 | 平面罗列 | 分层叠加（环境/动作/情绪） | 音效分层结构 |

### 2.3 专业度层面
| 维度 | 当前状态 | 目标状态 |
|---|---|---|
| 可复现性 | 中等（有人工解读空间） | 高（秒级指令精确） |
| 电影感 | 基础（能看） | 专业（有质感） |
| 品控一致性 | 依赖案例 | 依赖规则 |

## 四、关键决策点

### 4.1 保留现有结构
✅ 保留三层路由（创作/反推 → 类型 → 单段/多段）
✅ 保留L1/L2规则体系
✅ 保留现有文件组织结构

### 4.2 格式升级不破坏兼容性
- 新格式向下兼容：旧案例依然可用
- 渐进式升级：先升级核心类型（吃播/口播），再扩展
- 双模板并存：保留简化版模板供快速生成，专业版模板供精细打磨

### 4.3 专业度分级
考虑提供两档输出：
- **标准版**：当前格式优化（4秒时间码+基础镜头语言）
- **电影版**：新格式（2秒时间码+电影级镜头语言+四层结构）

用户可通过关键词选择：
- "生成一个吃播提示词" → 标准版
- "生成一个电影级吃播提示词" → 电影版
