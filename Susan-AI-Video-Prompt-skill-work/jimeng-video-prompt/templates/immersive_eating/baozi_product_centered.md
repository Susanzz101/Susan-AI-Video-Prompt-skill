# 酱肉包子·产品俯拍+人物角落构图

## 案例背景

**用户需求来源**：2026-07-14对话
**核心痛点**：学员生成的视频"脸部太大，产品太小"，需要突出产品为主体的构图
**目标效果**：产品占据画面中下方70%，人物（仅嘴部）在右上角占15%

## 构图类型：产品俯拍+人物角落

### 适用场景
- 需要展示"一盘/一堆"产品的视觉冲击力
- 产品需要绝对主导画面，人物只起"有人在吃"的暗示作用
- 适合堆叠摆盘的食物（包子、鸡爪、小龙虾、水饺、点心等）

### 构图特征
```
┌─────────────┐
│背景  [嘴+鼻]│ ← 人物在右上角15%
│      [手]   │
│   包包包    │ ← 产品在中下方70%
│  包包包包   │    一盘堆叠的包子
│ 包包包包包  │
│  [白盘子]   │
└─────────────┘
```

### 与传统构图的区别

| 对比项 | 传统半身构图 | 产品俯拍构图 |
|---|---|---|
| 机位角度 | 平视/略仰拍 | 俯拍45度 |
| 人物占比 | 50-60% | 10-15% |
| 产品占比 | 30-40% | 70-80% |
| 人物位置 | 画面中上方 | 画面角落（右上或左上） |
| 产品位置 | 画面下方1/3 | 画面中下方主体 |
| 产品形态 | 单个/手持 | 一盘堆叠/多个 |
| 背景处理 | 清晰入镜（车内/街边） | 可虚化，突出产品 |

## 提示词关键技巧拆解

### 1. 机位描述（最关键！）
```
俯拍特写固定机位（镜头从上往下45度角拍摄）
```
**为什么要俯拍？**
- 俯拍才能同时拍到"下方的产品全貌"和"上角的人物嘴部"
- 45度角是最佳角度：既能看到产品层次，又能看到人物动作

### 2. 空间布局描述（核心！）
```
画面中下方70%是一个白色瓷盘装满一堆酱肉包（堆叠摆放看到多个包子层次）
画面右上角仅露出模特的嘴巴鼻子下半部分和下巴占画面15%
```
**关键要点**：
- **明确分区**：中下方=产品区，右上角=人物区
- **明确占比**：70% vs 15%（数字比"中心位置"更精确）
- **产品形态**：一盘堆叠，不是单个（视觉冲击力更强）

### 3. 每个分镜都重复构图约束
```
画面中下方...占据主体
画面右上角...
盘中包子堆始终占据画面主体
```
**为什么要反复写？**
- 即梦在生成多分镜时容易"遗忘"前面的构图设置
- 每个时间段都要重新强调产品占比和人物位置

### 4. 人物动作描述
```
右手从画面右侧伸入拿起...
画面右上角模特嘴巴...
```
**关键要点**：
- 每次都标注"画面右上角"明确位置
- 手部动线清晰（从右侧伸入→连接人物和产品）

### 5. 产品描述细节
```
一个白色瓷盘装满一堆酱肉包（堆叠摆放看到多个包子层次）
能清晰看到每个包子表面的酱汁光泽
能看到包子之间挤压的褶皱和流淌的酱汁
```
**关键要点**：
- 承载物（白色瓷盘）也要描述，增加产品区域占比
- 强调产品的"堆叠层次感"和"细节质感"

## 常见问题诊断

### 问题1：AI还是把人物放中间了
**原因**：机位描述不够明确
**解决方案**：在开头加强制约束
```
【重要】画面构图以产品为绝对主体，人物脸部仅作为陪体出现在画面右上角边缘。
俯拍特写固定机位从正上方偏右侧45度角往下拍摄...
```

### 问题2：产品占比还是不够大
**解决方案**：调整占比描述
```
画面中下方80%是一个大白瓷盘装满堆叠的酱肉包
画面右上角仅露出模特的下嘴唇和下巴占画面10%
```

### 问题3：看不到产品层次感
**解决方案**：增加堆叠和细节描述
```
一堆酱肉包堆叠成小山状摆放（能看到三层包子重叠），
最上层包子表面酱汁流淌到下层包子上，
能清晰看到每个包子的褶皱纹理和光泽
```

## 适用品类扩展

这个构图适合所有"可堆叠摆盘"的食物：

| 食物类型 | 堆叠方式 | 承载物 | 关键动作 |
|---|---|---|---|
| 包子/饺子 | 小山状堆叠 | 白瓷盘/竹蒸笼 | 撕开见馅+咬下 |
| 鸡爪 | 交叠堆放 | 黑色餐盘/一次性餐盒 | 掰开见骨+撕咬 |
| 小龙虾 | 散铺堆叠 | 大圆盘/不锈钢盆 | 剥壳+吸虾黄 |
| 烧烤串 | 竖立交错 | 烤盘/锡纸托盘 | 撸串+咬肉 |

| 油炸小食 | 散堆 | 纸盒/塑料篮 | 拿起+咬碎 |

## 用户需求识别模式（对话记录）

### 需求表达1："镜头和产品对着脸部"
**初步理解**：产品和脸部同时在画面中
**实际需求**：产品为主体，脸部为辅助

### 需求表达2："脸部太大，产品太小"
**痛点识别**：构图比例失衡
**核心问题**：机位角度不对（平视导致脸部占比过大）

### 需求表达3："固定人物半脸的效果，产品为中心"
**初步方案**：半脸在角落+产品居中
**测试反馈**：产品占比仍不够

### 需求表达4："脸部很小，镜头只对着嘴巴，主要突出产品"
**关键信号**：嘴部特写
**调整方向**：压缩人物范围，扩大产品占比

### 需求表达5："人物要在右上角这种位置，而不是正中央"（提供参考图）
**最终确认**：俯拍构图+人物角落+产品主导
**参考图特征**：
- 俯拍45度
- 人物（嘴+鼻下半）在右上角15%
- 产品（一盘堆叠）在中下方70%
- 手部从右侧伸入连接人物和产品

### 对话模式总结

**识别信号词**：
- "镜头对着..." → 关注镜头角度
- "脸部太大/太小" → 关注占比问题
- "产品为中心" → 关注主体定位
- "只对着嘴巴" → 关注人物范围
- "右上角这种位置" → 关注空间布局

**迭代模式**：
1. 用户描述效果 → 生成初版提示词
2. 用户反馈问题 → 诊断根因（机位/占比/位置）
3. 针对性调整 → 重新生成
4. 提供参考图 → 精确复刻

**关键原则**：
- 不要假设用户需求，基于描述和参考图精确理解
- 每次调整都要说明"为什么这样改"
- 提供对比图示帮助用户理解构图差异
