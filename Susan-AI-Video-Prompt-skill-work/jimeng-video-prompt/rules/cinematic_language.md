# 电影级镜头语言规范

本文档为即梦视频提示词提供电影级镜头语言词库，确保输出的提示词具备专业的视觉表达能力。

---

## 一、景别系统（7级精细分类）

景别决定画面信息量和情绪距离，从远到近：

### 远景（Extreme Wide Shot）
- **定义**：展示大范围环境，人物占画面1/4以下
- **作用**：建立场景/展示空间关系/营造孤独感
- **示例**：`{远景/展示整条街道，人物在画面右下角}`

### 全景（Wide Shot）
- **定义**：展示人物全身+周边环境（头到脚完整）
- **作用**：展示人物与环境的关系/肢体动作完整展现
- **示例**：`{全景/模特全身站在厨房中央，背景橱柜清晰可见}`

### 中景（Medium Shot）
- **定义**：膝盖以上到头顶
- **作用**：平衡人物与环境，展示上半身动作
- **示例**：`{中景/模特从腰部往上入镜，手部动作清晰}`

### 半身中景（Medium Close-up）
- **定义**：腰部/胸部以上到头顶（最常用）
- **作用**：突出人物表情+手部动作，带货视频主力景别
- **示例**：`{半身中景/模特胸部以上，双手可完整展示产品}`

### 近景（Close-up）
- **定义**：肩部以上到头顶，或产品完整特写
- **作用**：捕捉表情细节/产品全貌展示
- **示例**：`{近景/模特肩部以上，表情清晰可见}`
- **示例**：`{近景/【产品】完整占据画面中心70%}`

### 特写（Big Close-up）
- **定义**：面部局部（眼睛/嘴唇）或产品关键部位
- **作用**：极致细节/制造张力/ASMR质感
- **示例**：`{特写/模特嘴唇和下巴，咬下食物的瞬间}`
- **示例**：`{特写/【产品】瓶盖旋开的螺纹特写}`

### 大特写（Extreme Close-up）
- **定义**：微距级别，眼球/皮肤纹理/产品微观细节
- **作用**：冲击力/质感展示/高端感
- **示例**：`{大特写/眼球中倒映产品轮廓，睫毛清晰}`
- **示例**：`{大特写/液体倾倒瞬间的流动纹理}`

## 二、运镜方式（8种核心运镜）

运镜创造动态感和情绪递进，是电影感的关键。

### 2.1 推镜（Push in / Dolly in）
镜头向被摄主体推进，聚焦注意力。

**分类**：
- **缓推**：2-4秒缓慢推进，营造情绪递进
  - 示例：`{半身中景→近景/缓推3秒}`
  - 用途：口播开场、产品揭示、情绪酝酿
  
- **快推**：1秒内快速推进，制造冲击
  - 示例：`{中景→特写/快推1秒/配合音效}`
  - 用途：剧情反转、惊喜时刻、产品爆点

**运镜公式**：`{起始景别→结束景别/缓推X秒}` 或 `{起始景别→结束景别/快推}`

### 2.2 拉镜（Pull out / Dolly out）
镜头远离被摄主体，揭示环境或制造反差。

**应用场景**：
- 从产品特写拉到人物使用场景（揭示用途）
- 从人物表情拉到豪车内饰（制造反差）
- 示例：`{特写→中景/缓拉2秒/揭示车内环境}`

### 2.3 横摇（Pan）
镜头水平左右移动，展示序列或空间。

**应用场景**：
- 展示一排产品/食物序列
- 从A物体摇到B物体建立关联
- 示例：`{横摇镜头/从左到右扫过三个产品/每个停顿1秒}`
- 示例：`{横摇/从模特手中的产品摇至面部表情}`

### 2.4 竖摇（Tilt）
镜头垂直上下移动。

**应用场景**：
- 从脚到头扫描（服装展示）
- 从产品摇到人物表情（建立使用关系）
- 示例：`{竖摇/从桌上的【产品】缓慢上摇至模特满意表情}`

### 2.5 跟镜（Follow / Tracking）
镜头跟随人物或物体移动，保持相对位置不变。

**应用场景**：
- 跟随手部动作（打开产品/涂抹动作）
- 跟随食物从盘子到嘴边
- 示例：`{跟镜/随模特右手从桌面拿起产品至胸前}`

### 2.6 环绕镜头（Orbit / 360°）
镜头围绕主体旋转，展示360度全貌。

**应用场景**：
- 产品全方位展示
- 服装穿搭展示
- 示例：`{环绕镜头/顺时针180度/从正面绕至侧面}`
- **注意**：即梦对360度环绕支持有限，建议用180度或分段拍摄

### 2.7 升降镜头（Crane / Boom）
镜头垂直升高或降低。

**应用场景**：
- 从俯拍降至平视（制造"发现"感）
- 从平视升至俯拍（展示全局）
- 示例：`{升镜/从平视中景缓慢升至俯拍/揭示桌面产品布局}`

### 2.8 固定机位（Static / Locked）
镜头完全静止，所有运动来自被摄主体。

**应用场景**：
- 突出动作本身（吃播咀嚼/口播讲解）
- 稳定构图（正面采访/产品展示）
- 示例：`{固定机位/正面半身中景}`
- **黄金法则**：沉浸式吃播首选固定机位，避免过度运镜干扰食物本身

## 三、景深控制（虚化的艺术）

景深（Depth of Field）控制前后景清晰范围，影响画面层次和焦点。

### 3.1 浅景深（Shallow DOF）
**参数**：f/1.4, f/1.8, f/2.8
**特征**：背景大幅虚化，主体突出
**作用**：
- 突出产品/人物，隔离杂乱背景
- 制造高级感/电影感
- 营造梦幻/柔美氛围

**标注格式**：`{特写/景深f/2.8/背景虚化成光斑}`

**应用场景**：
- 产品特写（背景虚化突出产品）
- 口播人物近景（虚化背景突出讲解者）
- 示例：`{近景/景深f/1.8/模特面部清晰，背景咖啡厅环境虚化成暖黄光斑}`

### 3.2 深景深（Deep DOF）
**参数**：f/8, f/11, f/16
**特征**：前后景都清晰
**作用**：
- 展示环境细节（车内吃播需要看清真皮座椅/车标）
- 制造真实感/纪实感
- 多层次信息传递

**标注格式**：`{半身中景/景深f/11/人物和背景车内环境均清晰}`

**应用场景**：
- 车内吃播（需要展示豪车内饰细节）
- 街边场景（需要展示烟火气）
- 多产品排列（所有产品都清晰）
- 示例：`{中景/景深f/8/模特、手中产品、背后货架商品均清晰可见}`

### 3.3 景深过渡（Rack Focus）
焦点从A物体切换到B物体，前景虚化后景清晰或反之。

**应用场景**：
- 从产品切换到人物表情（建立情感联系）
- 从人物切换到产品（引导注意力）
- 示例：`{特写/焦点从前景【产品】切换至后景模特笑脸/背景虚化转清晰}`

## 四、光影描述（Light & Shadow）

光影是视觉质感的核心，决定画面氛围和高级感。

### 4.1 光位（Light Position）

**顶光（Top Light）**：
- 从正上方照射，产生向下阴影
- 作用：神圣感/戏剧性
- 避免：容易形成眼窝阴影，需谨慎使用
- 示例：`顶光直射，产品在桌面上投下清晰圆形阴影`

**侧光（Side Light）**：
- 从侧面45-90度照射
- 作用：立体感强/层次丰富/质感突出
- **黄金角度**：45度侧光（伦勃朗光）
- 示例：`左侧45度柔光打亮面部，鼻梁右侧有明显高光，左脸颊阴影形成三角光区`

**逆光（Back Light / Rim Light）**：
- 从被摄体后方照射
- 作用：轮廓光/营造氛围/梦幻感
- 示例：`逆光从身后透过发丝形成金色轮廓光，面部柔光补光避免过暗`

**顺光（Front Light）**：
- 从镜头方向直接照射
- 作用：明亮均匀，细节清晰
- 缺点：立体感弱，需配合侧光
- 示例：`正面柔光均匀照亮，无明显阴影，肤色透亮`

**底光（Bottom Light）**：
- 从下方照射（少用）
- 作用：恐怖感/诡异感/创意效果
- 示例：`底光从桌面反射，营造神秘氛围`

### 4.2 光质（Light Quality）

**硬光（Hard Light）**：
- 特征：阴影边缘清晰锐利，对比度高
- 光源：直射阳光/聚光灯/裸灯泡
- 作用：力量感/清晰感/高对比
- 示例：`午后直射阳光形成清晰硬阴影，产品轮廓锐利`

**柔光（Soft Light）**：
- 特征：阴影边缘柔和渐变，对比度低
- 光源：柔光箱/漫射阳光/阴天光
- 作用：柔美/舒适/高级感（带货视频主流）
- 示例：`窗外漫射自然光均匀柔和，面部阴影过渡自然无明显边界`

### 4.3 光效描述词库

**高光（Highlight）**：
- `鼻梁高光清晰` 
- `瓶身右上角有明显高光点`
- `眼睛有自然眼神光（Catchlight）`

**阴影（Shadow）**：
- `鼻翼两侧有柔和阴影层次`
- `产品底部阴影自然过渡至桌面`
- `面部左侧阴影形成三角光区（伦勃朗光）`

**轮廓光（Rim Light / Edge Light）**：
- `头发边缘有金色轮廓光`
- `肩膀线条被逆光勾勒出明亮边缘`

**环境光（Ambient Light）**：
- `车内氛围灯暖黄色均匀照亮座椅`
- `咖啡厅暖光散射形成舒适环境光`

### 4.4 光影组合公式

**公式**：`光位 + 光质 + 具体光效`

示例：
- `左侧45度柔光照射，鼻梁有清晰高光，右脸颊有柔和阴影过渡，眼睛有明显眼神光`
- `逆光从窗外透入形成金色轮廓光，正面补柔光避免脸部过暗，整体通透有层次`

## 五、构图法则（Composition）

构图决定画面平衡和视觉引导。

### 5.1 三分法则（Rule of Thirds）
将画面横竖各三等分，重要元素放在交叉点或分割线上。

**应用**：
- 人物眼睛放在上三分线
- 产品放在左/右三分线
- 地平线放在上/下三分线

**示例**：`{中景/三分法构图，模特眼睛位于画面上三分线交点，产品位于下三分线}`

### 5.2 中心构图（Center Composition）
主体居中，四周对称或留白。

**应用**：
- 产品展示（强调主体）
- 正面口播（稳定对称）

**示例**：`{特写/中心构图，【产品】居中占画面60%，四周均匀留白}`

### 5.3 对角线构图（Diagonal Composition）
利用对角线制造动态感和引导视线。

**应用**：
- 产品序列排列
- 人物动态姿态

**示例**：`{全景/对角线构图，模特身体从左下延伸至右上，产品沿对角线排列}`

### 5.4 留白构图（Negative Space）
主体占一侧，另一侧留白用于字幕/信息。

**应用**：
- 需要后期加字幕的视频
- 营造呼吸感/高级感

**示例**：`{半身中景/模特位于画面右侧2/3，左侧留白1/3用于字幕区}`

### 5.5 框架构图（Frame within Frame）
用前景元素形成"画框"包围主体。

**应用**：
- 门框/窗框/镜子框住人物
- 营造纵深感

**示例**：`{中景/透过车窗框架看模特吃东西，车窗边缘形成自然画框}`

## 六、切换方式（Transition）

切换方式决定镜头间的节奏和情绪连贯性。

### 6.1 硬切（Cut）
直接切换，最常用。

**示例**：`{硬切至下一镜头}`

### 6.2 卡点硬切（Beat Cut）
配合音乐/音效节奏切换。

**应用**：
- 服装换装卡点
- 产品多角度展示配合鼓点

**示例**：`{卡点硬切/配合鼓点节奏}`

### 6.3 淡入淡出（Fade In / Fade Out）
画面渐渐显现或消失至黑/白。

**应用**：
- 段落开始/结束
- 时间流逝暗示

**示例**：`{淡入/从黑场渐显}`

### 6.4 溶解/叠化（Dissolve / Cross Dissolve）
两个镜头叠加过渡。

**应用**：
- 时间流逝
- 梦幻感/回忆感

**示例**：`{溶解过渡至下一场景/持续1秒}`

### 6.5 擦除（Wipe）
一个镜头像帘子一样推开另一个。

**应用**：
- 创意转场
- 活泼轻快风格

**示例**：`{从左至右擦除转场}`

### 6.6 无缝转场（Match Cut）
利用相似元素/动作/位置实现流畅切换。

**应用**：
- 多段视频衔接
- 制造惊喜

**示例**：`{匹配转场/前一镜手放下产品，后一镜同位置另一产品出现}`

## 七、动作拆解六维度

精准描述动作，避免笼统词汇。

### 维度1：身体部位
- 右手/左手/双手/食指和拇指/手掌/指尖/手背
- 头部/肩膀/腰部/膝盖
- 示例：`右手食指和拇指捏住瓶盖边缘`

### 维度2：起点→终点（空间路径）
- 从画面下方→至胸前位置
- 从右侧→划向左侧
- 从桌面→举至眼前
- 示例：`模特右手从画面下方缓缓托起【产品】至胸前位置`

### 维度3：速度/节奏
- 缓缓/快速/迅速/停顿0.5秒/加速/减速
- 示例：`缓缓举起停顿1秒后轻轻旋转`

### 维度4：力度/质感
- 轻轻/用力/紧握/松开/托起/捏住/按压/滑动
- 示例：`轻握瓶身中部避开标签区`

### 维度5：空间位置
- 瓶身中部/标签区/底部/顶端
- 画面中心/右下角/上三分线
- 示例：`手指位于瓶身中下部，避开标签让正面完全露出`

### 维度6：附加动作
- 旋转/倾斜/轻摇/上下移动/左右摆动
- 示例：`停顿0.5秒后轻轻旋转瓶身45度使标签完全对准镜头`

**完整示例**：
```
模特右手（维度1）从画面下方（维度2起点）缓缓（维度3）托起（维度4）
【产品】至胸前位置（维度2终点），手指轻握（维度4）瓶身中部（维度5）
避开标签区，停顿0.5秒（维度3）后轻轻旋转（维度6）瓶身使标签完全对准镜头。
```

## 八、情绪弧光设计（Emotional Arc）

单个15秒视频的情绪变化曲线。

### 8.1 沉浸式吃播情绪弧光
```
00-03秒：期待（眼神看食物，吸口水）
03-08秒：瞬间满足（咬下的瞬间闭眼，眉头舒展）
08-12秒：享受回味（咀嚼中的陶醉，嘴角微笑）
12-15秒：停不下来（手伸向下一个，意犹未尽）
```

### 8.2 口播种草情绪弧光
```
00-03秒：亲切开场（眼神直视镜头，微笑真诚）
03-08秒：讲解时的认真（眼神在产品和镜头间切换，表情专注）
08-12秒：使用时的惊喜（眉毛上扬，嘴角惊喜弧度）
12-15秒：分享时的满足（笑容放大，点头确认）
```

### 8.3 剧情类情绪弧光
```
第一幕：冲突情绪（皱眉/不满/紧张）
第二幕：转折情绪（意外/惊讶/困惑）
第三幕：恍然大悟（眼睛睁大→笑容展开）
第四幕：爽感/满足（释然微笑/得意神情）
```

## 九、产品状态追踪（Product Tracking）

每个分镜明确描述产品的6个维度。

### 产品六维度
1. **位置**：画面中心/下方1/3/右侧/手中/桌上/使用中
2. **占比**：占画面20%/50%/80%
3. **角度**：正面/侧面45度/斜上方30度/俯拍
4. **状态**：静置/被托举/被打开/使用中/流动中
5. **光影**：高光在右上角/阴影在底部/逆光轮廓清晰
6. **与人物关系**：被右手握住/在眼神注视下/被嘴唇触碰

### 产品线示例（口播15秒）
```
[00:00-03]：产品在包装盒中（制造悬念）
[03-06]：产品被双手托起至胸前，正面对镜头，占画面40%
[06-10]：产品特写，占画面70%，高光清晰，展示标签
[10-15]：产品使用中，瓶口倾斜液体流出，占画面下方1/3
```

## 十、音效分层结构（Sound Design Layers）

音效分三层叠加，营造立体声场。

### 三层结构
```
(音效：
  [环境底噪层] 描述环境氛围音（车内/咖啡厅/街边）
```

## 十二、使用原则

### 原则1：根据类型选择镜头语言
- **沉浸式吃播**：固定机位为主，偶尔特写推镜，深景深展示环境
- **口播类**：固定机位+偶尔缓推，浅景深突出人物
- **剧情类**：运镜丰富（推拉摇移组合），景深变化制造层次

### 原则2：不过度堆砌术语
- 每个镜头标注2-3个核心要素即可
- 避免：`{半身中景固定机位景深f/2.8左侧45度柔光三分法构图暖黄色调}`
- 推荐：`{半身中景/固定机位/景深f/2.8}` + 文字描述光影

### 原则3：术语服务于视觉目标
- 想要突出产品 → 特写+浅景深+中心构图
- 想要展示环境 → 中景/全景+深景深
- 想要营造情绪 → 推镜+光影描述+情绪弧光

### 原则4：即梦平台限制
- 避免过于复杂的运镜（360度环绕/复杂升降）
- 优先使用固定机位+简单推拉
- 复杂效果通过剪辑实现，单段保持简洁
