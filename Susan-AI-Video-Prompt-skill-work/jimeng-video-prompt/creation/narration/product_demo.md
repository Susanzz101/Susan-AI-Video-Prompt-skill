# 口播·功能演示型提示词 Skill

## 概述

本skill用于生成"展示产品功能/操作步骤"的口播带货视频提示词。核心目标：让观众看完觉得"这个东西有用，我也需要"，通过真实场景下的操作演示建立信任。

典型品类：厨房小工具、清洁用品、农资产品、电子配件、收纳工具等"功能驱动型"产品。

## L2覆盖声明

- L2-03 台词：**有台词**
- L2-04 音色：**使用【音色】**
- L2-02 BGM：**有（卡点音乐）**，但非强制，用户可指定无BGM
- L2-08 音效：环境底噪+产品操作音效（如喷雾声、切割声、开关声）
- L2-09 开场：痛点/功能钩子开场
- L2-10 收尾：轻度引流

```
[时间码], {景别/运镜/景深}

(音效：

```

**注意**：所有时间码使用方括号 `[]`，粒度为2-3秒/分镜。

## 电影级镜头语言应用

### 口播功能演示的镜头语言选择

**首选镜头组合**：
- **固定机位** 50%（稳定展示操作过程）
- **跟镜** 30%（跟随手部操作动作）
- **偶尔缓推** 20%（从中景推至特写，强调产品细节）

**景别分配**：
- **半身中景**：开场建立（人物+场景+产品）
- **近景**：操作演示（手部+产品清晰可见）
- **特写**：产品细节/效果展示

**景深控制**：
- **浅景深f/2.8**：虚化背景，突出人物和产品（主流选择）
- **中景深f/5.6**：保留部分背景环境细节，增强真实感

**光影控制**：
- **侧光45度+正面补光**：立体感+细节清晰
- **自然光从窗外照入**：真实生活感
- **避免顶光**：容易产生不自然阴影

**运镜特点**：
- ✅ 跟镜跟随手部操作（展示使用过程）
- ✅ 固定机位展示操作结果（稳定可信）
- ✅ 偶尔缓推至产品特写（强调卖点）
- ❌ 避免快速运镜（干扰观众理解操作）

## 核心规则

### 规则1：三段式结构——痛点→演示→效果

功能演示型视频的叙事结构高度统一：

**第一段（0-4s）痛点开场**：
- 用生活场景展示"没有这个产品时的痛苦"
- 台词用真实口语，不要广告腔
- 例：「削个苹果搞得满桌都是皮？」「我这阳台的小番茄又生虫了」

**第二段（4-10s）功能演示**：
- 展示产品使用的完整操作过程
- 每一个操作步骤都要有对应的视觉动作
- 台词同步解说操作要点（"来回推都能削""叶子正反面都喷一下"）
- 产品的核心卖点要在操作中自然体现，不要脱离操作单独念卖点

**第三段（10-15s）效果展示+轻度引流**：
- 展示使用后的效果对比（干净的台面/健康的叶片/整洁的收纳）
- 台词用结果说话（"第二天叶子就干净了""台面干干净净"）
- 最后一句轻度引流，不要"小黄车"套话
- 例：「阳台党必备」「厨房有这个真的省心」

### 规则2：台词风格——邻居分享感

功能演示型台词的关键是**"像邻居在跟你推荐好用的东西"**：

**要做到的**：
- 用生活化口语（"搞得满桌都是""真的省心"）
- 加入"邻居推荐""闺蜜安利"等信任背书（"邻居推荐我用这个"）
- 操作解说要像真正用过的人才知道的细节（"叶子正反面都喷一下"）
- 台词密度适中，留出"看操作"的视觉空间

**不要做的**：
- 广告腔（"本产品采用XX技术""荣获XX认证"）
- 堆砌卖点（一句话里塞3个以上卖点）
- 夸张承诺（"用一次就好""永远不会坏"）

### 规则3：操作动作——每步都要有视觉对应

台词提到的每一个功能/卖点，画面中必须有对应的操作动作在同时发生。观众是"看到"才相信，不是"听到"就相信。

**正确示例**：
- 台词「双向刀头来回推都能削」→ 画面：模特手持削皮器来回推动
- 台词「低毒的」→ 画面：模特指尖捏开包装倒出少量白色颗粒

**错误示例**：
- 台词「这个产品有三大优点」→ 画面：模特举着产品对镜头说话（纯口播无操作）

### 规则4：场景选择——产品使用的真实场景

功能演示型产品的场景必须是该产品真正会被使用的地方：
- 厨房工具 → 厨房操作台、原木桌面
- 农资产品 → 阳台花盆、菜园
- 清洁工具 → 浴室、厨房
- 收纳工具 → 衣柜、书桌

不要用"广告棚""纯白背景"——会破坏"真实使用"的信任感。

## 完整提示词生成流程（v2.0电影级格式）

### Step 1：识别产品类型和核心功能
- 产品品类是什么？（厨房/农资/清洁/收纳）
- 解决什么痛点？
- 核心操作步骤是什么？

### Step 2：设计三段式结构
```
第一段（0-4秒）：痛点开场
第二段（4-10秒）：功能演示
第三段（10-15秒）：效果展示+轻度引流
```

### Step 3：设计分镜节奏（5-6个分镜）
15秒视频的标准分镜节奏：
```
[0-3秒]：痛点展示 {半身中景/固定机位/景深f/2.8}
[3-5秒]：产品引入 {近景/固定机位}
[5-8秒]：操作演示主步骤 {近景/跟镜}
[8-11秒]：操作演示细节 {特写/缓推}
[11-13秒]：效果对比展示 {近景/固定机位}
[13-15秒]：总结+轻度引流 {半身中景/固定机位}
```

### Step 4：逐镜填充四层描述

**痛点开场示例**：
```
[00:00-00:03], {半身中景/固定机位/景深f/2.8}
动作：模特蹲在阳台花盆前，单手轻轻翻起一片番茄叶子，叶片上有明显孔洞和发黄卷曲痕迹。口播台词：「我这阳台的小番茄又生虫了，叶子全被啃成这样。」
情绪：眉头皱起，眼神看向镜头，表情真实带点无奈，整个状态是遇到问题的困扰感。
环境：阳台绿色植物花盆+纱窗虚化背景，自然光从窗外照入形成侧光。
(音效：
  [环境层] 阳台环境鸟鸣底噪
  [动作层] 叶片翻动细微声
  [人物层] 自然呼吸声+语调中的无奈感
)
```

**操作演示示例**：
```
[00:05-00:08], {近景/跟镜/景深f/2.8}
动作：模特右手拿着已兑好水的小喷壶，对着番茄植株均匀喷洒，水雾细密覆盖叶片正反面。口播台词：「叶子正反面都喷一下，重点喷虫害严重的地方。」
情绪：眼神专注看着喷洒动作，表情认真，嘴角微微上扬显示出"这个方法有效"的自信。
环境：镜头跟随手部动作移动，背景虚化突出喷洒细节，水珠在自然光下闪着光泽。
(音效：
  [环境层] 阳台环境底噪
  [动作层] 喷壶喷雾嘶嘶声+水珠落叶清脆声
  [人物层] 呼吸声+语调中的专业感
)
```

### Step 5：确保台词与动作同步
- 台词提到的每个功能点，画面中必须有对应操作
- 台词密度适中，留出"看操作"的时间
- 台词用邻居分享感，不用广告腔

### Step 6：质量自检清单

**格式检查**：
- [ ] 时间码使用方括号 `[]`
- [ ] 时间粒度为2-3秒/分镜
- [ ] 每个分镜包含四层（镜头/动作+台词/情绪/环境/音效）
- [ ] 台词用「」标注

**内容检查**：
- [ ] 字符数在2000以内
- [ ] 三段式结构完整（痛点→演示→效果）
- [ ] 台词与画面操作同步
- [ ] 台词是邻居分享感（非广告腔）
- [ ] 收尾是轻度引流（非"小黄车"套话）

**专业度检查**：
- [ ] 动作拆解精确（操作步骤清晰可复现）
- [ ] 情绪弧光：困扰→专注→自信满足
- [ ] 场景是产品真实使用场景
- [ ] 镜头语言：固定机位+跟镜+偶尔缓推

## 完整案例示例（v2.0电影级格式）

### 示例：伏魔吡虫啉杀虫剂·阳台场景（15秒）

**头部信息块**：
```
写实真人风格，8K超高清，竖屏9:16。中文台词无字幕，用这个音色【音色】。
无背景音乐，有环境音效和产品操作音效。
自然光暖白色调，窗外自然光照入形成侧光45度。iPhone原相机真实拍摄感。

【人物】长发扎马尾，白色T恤+牛仔裤，蹲在阳台。
【场景】城市阳台，绿色植物花盆排列，纱窗虚化背景，自然光从右侧窗外照入。浅景深f/2.8虚化背景突出人物和植物。
【产品】伏魔吡虫啉70%水分散粒剂小袋装，初始放在花盆旁。

整体氛围真实生活分享感。
```

**分镜描述块**：
```
[00:00-00:03], {半身中景/固定机位/景深f/2.8}
动作：模特蹲在阳台花盆前，右手轻轻翻起一片番茄叶子至胸前高度，叶片上有明显孔洞和发黄卷曲痕迹清晰入镜。口播台词：「我这阳台的小番茄又生虫了，叶子全被啃成这样。」
情绪：眉头皱起看向镜头，眼神中有真实的无奈，嘴角微微下撇，整个表情是遇到问题的困扰状态。
环境：阳台绿色番茄植株在前景，背景纱窗和其他盆栽虚化成浅绿光斑，自然光从右侧照入在叶片上形成高光。
(音效：
  [环境层] 阳台环境鸟鸣底噪+远处车流声隐约
  [动作层] 叶片翻动细微沙沙声
  [人物层] 自然呼吸声+语调中的无奈叹气
)

[00:03-00:05], {近景/固定机位/景深f/2.8}
动作：模特从一旁拿起一小袋"伏魔"吡虫啉产品举到胸前展示包装正面对准镜头，另一手用指尖捏开包装口，倒出少量白色颗粒在掌心。口播台词：「邻居推荐我用这个，3克一袋兑水就行，低毒的。」
情绪：眉头舒展，眼神从产品移向镜头，嘴角微微上扬带出"找到解决方案"的轻松感。
环境：背景虚化成暖绿光斑，焦点全在手中产品和白色颗粒上，侧光照亮包装正面文字清晰可见。
(音效：
  [环境层] 阳台底噪
  [动作层] 包装袋撕开清脆声+颗粒倒出细微声+颗粒在掌心滚动声
  [人物层] 轻松语调
)

[00:05-00:08], {近景/跟镜/景深f/2.8}
动作：模特右手拿着已经兑好水的透明小喷壶，对着番茄植株从上到下均匀喷洒，水雾细密覆盖在叶片正反面，叶片上的水珠在自然光下闪着光泽。口播台词：「叶子正反面都喷一下，重点喷虫害严重的地方。」
情绪：眼神专注看着喷洒的叶片，表情认真，眉眼间透出"这个操作我很熟练"的自信和专业感。
环境：镜头跟随手部喷洒动作缓慢移动，背景植物虚化，焦点始终在喷雾和叶片接触的瞬间。
(音效：
  [环境层] 阳台鸟鸣+微风吹动叶片声
  [动作层] 喷壶喷雾嘶嘶声持续+水珠落在叶片上清脆声
  [人物层] 均匀呼吸声+专业解说语调

[00:08-00:11], {特写/缓推至大特写2秒/景深f/2.8}
动作：镜头聚焦在刚喷洒过的番茄叶片特写，水珠均匀分布在叶片表面，叶片翠绿有光泽。镜头从特写缓慢推进至叶脉纹理大特写。口播台词：「这个专门针对蚜虫、白粉虱，安全又有效。」
情绪：无人物出镜，画外音语调平稳专业，透出对产品的信任感。
环境：背景完全虚化成浅绿光斑，焦点全在叶片水珠细节上，自然光从侧面打亮叶片形成通透质感。
(音效：
  [环境层] 阳台底噪轻微
  [动作层] 水珠缓慢滑落叶片声
  [人物层] 画外音平稳语调
)

[00:11-00:13], {近景/固定机位/景深f/2.8}
动作：镜头切换至另一株番茄植株的健康叶片特写，叶片干净舒展无孔洞，绿油油有光泽，与开场被虫啃的叶片形成鲜明对比。口播台词：「第二天叶子就干净了，虫子全没了。」
情绪：无人物出镜，画外音语调中带着满意和欣喜，"见效快"的惊喜感。
环境：健康叶片在阳光下翠绿通透，背景虚化，焦点在叶片光泽和完整性上。
(音效：
  [环境层] 阳台环境音+鸟鸣欢快
  [动作层] 微风吹动叶片轻微声
  [人物层] 满意语调

[00:13-00:15], {半身中景/固定机位/景深f/2.8}
动作：模特对镜头微笑，右手举起伏魔产品小袋在胸前位置，产品包装正面对准镜头。口播台词：「阳台党必备，家里种菜的赶紧试试。」
情绪：眼神真诚看向镜头，嘴角自然微笑，眉眼舒展，整个表情是分享好物的满足和真诚推荐状态。
环境：背景阳台植物虚化成绿色光斑，模特和产品清晰入镜，自然光均匀照亮面部和产品。
(音效：
  [环境层] 阳台环境鸟鸣+轻柔自然收尾
  [动作层] 产品袋轻微晃动声
  [人物层] 真诚分享语调
)
```
