# 沉浸式服装展示提示词 Skill

## 概述

本skill用于生成沉浸式无台词服装展示类视频的即梦提示词。核心目标：让观众看完觉得"这件衣服穿上身好好看/好有气质"，而不是"这是一个AI在展示衣服"。

## L2覆盖声明

- L2-03 台词：**无台词**
- L2-04 音色：**不使用【音色】**
- L2-02 BGM：**视需求**——纯展示类可无BGM（环境音为主），卡点换装类需要BGM
- L2-08 音效：环境音+面料动态声（飘动声、摩擦声等）

## 核心规则

### 规则1：背景稳定性

**"固定背景"≠"固定机位"**——这是关键区别：
- 固定背景：背景环境不变，但镜头可以推/拉/小幅移动
- 固定机位：镜头完全不动

用户要求"背景不动"时，镜头依然可以做缓推/缓拉/小幅环绕，只要背景保持一致。如果用"固定机位"，画面会显得过于静态，人物表情容易僵硬。

### 规则2：人物表情自然度

服装展示类视频的表情自然度要求与吃播不同：

**吃播**：表情是对食物味道的反应（闭眼品味、皱眉享受）
**服装展示**：表情是"穿着这件衣服的自在状态"（松弛、慵懒、自信、若有所思）

**核心技巧：给表情一个"内在动机"**
- ❌「温柔直视镜头嘴角微扬眼神侧目带着自信」（摆拍式堆叠）
- ✅「低头看了一眼自己袖口花边，指尖轻轻拨弄了一下，嘴角不自觉上扬」（有动机的自然反应）

**推荐的"无意识小动作"**（建立真实感的关键信号）：
- 撩发到耳后
- 低头看自己衣服某个细节
- 轻轻拨弄/捏起面料
- 转身时长发自然甩动
- 头微微侧倾
- 看向远处又回过来

**推荐的"情绪状态词"**（代替"摆拍表情词"）：
- 松弛慵懒 / 若有所思 / 自在放松 / 像在感受面料 / 被自己衣服取悦的状态

### 规则3：面料动态——让衣服"活"起来

每个分镜都应该有至少一个面料动态细节，让画面"会呼吸"：

| 面料类型 | 动态细节描述 |
|---|---|
| 雪纺/纱质 | 袖口荷叶边随手部动作轻轻飘动 |
| 百褶裙/裤 | 裤摆/裙摆随转身自然摇摆、褶皱在侧面光下显出立体感 |
| 棉麻/宽松款 | 衣身随身体摆动自然晃动、宽松廓形的垂坠感 |
| 丝绸/缎面 | 面料在光线下流动反光、光泽感随角度变化 |
| 针织/毛衣 | 面料的柔软贴合感、手指按压后的回弹 |

### 规则4：展示逻辑——5步法

标准的服装展示视频遵循5步法（15秒内完成）：

1. **正面定场**（0-3s）：建立整体印象，重心放松自然站
2. **侧面线条**（3-6s）：展示腰身/版型侧面轮廓
3. **背面回眸**（6-9s）：背部版型+回眸建立人物感
4. **拉近细节**（9-12s）：面料质感/领口/袖口/扣子等细节
5. **收尾定格**（12-15s）：情绪收尾，自然定格

**注意**：这5步不是铁律，用户可能要求更少步骤或不同顺序。此为默认参考。

### 规则5：卡点换装类（特殊子类型）

当用户要求"卡点换装"时，与普通服装展示的规则差异：

- **需要BGM**：抖音火爆电子卡点音乐
- **多套衣服通过卡点硬切切换**：不描述"换装动作"，用硬切实现视觉换装
- **每套衣服对应一种情绪/姿态**：避免4套都是同一种表情
- **场景必须统一**：纯色背景/固定场景，确保换装的视觉连贯性
- **每套时间平均分配**：4套15秒 = 每套3.75秒

## 即梦生成风险提示

| 风险点 | 发生概率 | 应对方式 |
|---|---|---|
| 多分镜背景轻微漂移 | 较高 | 接受5-10%漂移，或分段独立生成后剪辑 |
| "背身回眸"脸部变形 | 中等 | 改为"侧身90度+头部回正" |
| 转身动作不连贯 | 中等 | 删除转身，改为直接切到新角度 |
| 面部表情僵硬 | 中等 | 加入"无意识小动作"触发自然表情 |
| 多套换装面部不一致 | 较高 | 即梦通病，可接受 |
