# 多段视频衔接一致性规则

## 适用场景

当视频总时长超过15秒时，需要拆分为多个15秒段分别生成。本规则确保多段视频在剪辑拼接后看起来像一条连贯的视频。

## 核心原则

**即梦的每一段都是独立生成的**——它不知道上一段是什么，也不知道下一段是什么。所以"一致性"完全依赖于提示词的精确重复描述，而不是即梦的"记忆"。

---

## 必须保持一致的要素

### 1. 人物一致性
- 每一段都使用相同的【人物】素材槽位图片
- 每一段都描述相同的服装/配饰/发型状态
- 如果第一段描述了「穿着白色棒球服」，后续每段都要重复这个描述

### 2. 场景一致性
- 每一段的场景描述必须完全相同（逐字复制）
- 包括：背景环境、光线条件、道具位置、色调风格
- **最佳实践**：把场景描述写成一个固定段落，多段之间直接复制粘贴

**示例——两段共享的场景描述**：
```
劳斯莱斯后座米色真皮座椅+车顶星空灯+车窗外夜市街边店铺招牌霓虹灯清晰可见，
面前腿上锡纸托着一整块切好的脆皮五花肉表皮金黄起泡油光锃亮
```
这段文字在第一段和第二段的提示词中完全一样。

### 3. 产品一致性
- 每一段都使用相同的【产品】素材槽位图片
- 产品在画面中的位置保持一致（如"面前碗里""腿上锡纸托盘"）

### 4. 音色一致性（口播/剧情类）
- 每一段都使用相同的【音色】
- 台词的语气风格保持一致（不要第一段活泼第二段严肃）

### 5. 色调/画质一致性
- 每一段的色调描述完全相同（如"暖黄高饱和色调"）
- 画质风格完全相同（如"iPhone原相机真实拍摄感"）

### 6. 机位一致性
- 除非有意设计镜头变化，否则每段机位描述保持一致
- 特别是车内吃播等有固定机位规范的类型

---

## 衔接点设计

### 动作衔接
第一段的最后一个动作和第二段的第一个动作之间需要有逻辑连续性：

**好的衔接**：
- 第一段结尾：「模特边咀嚼边从碗里拿起另一个包子」
- 第二段开头：「模特双手捏住包子两端缓缓掰开」
- 逻辑：拿起→掰开，动作连续

**差的衔接**：
- 第一段结尾：「模特闭眼大口咀嚼」
- 第二段开头：「模特从碗里拿起一个新的包子举到镜头前展示」
- 逻辑断裂：上一段还在嚼，下一段突然在展示新的

### 台词衔接（口播/剧情类）
- 第一段台词的最后一句和第二段台词的第一句之间不能有语义断裂
- 但也不能有跨段引用（不能说"刚才说到"）
- **最佳实践**：把30秒完整台词先写好，再按15秒切分，确保切分点在语义自然停顿处

### 音效衔接
- 第一段的收尾音效不要用"重低音收尾定格"（这是整条视频的终结信号）
- 只有最后一段的收尾才用定格收尾音效
- 中间段的收尾用"过渡性音效"（如持续的环境底噪、咀嚼声延续等）

## 多段提示词的实际写法

以30秒（2×15s）为例：

```
【第一段提示词】
参考抖音XX博主【人物】吃【产品】XX。竖屏9:16，15秒，无字幕无台词无背景音乐。
{色调}，{画质}，{机位}，{场景描述——完整版}，{食物状态描述}，整体氛围XXX。

(00:00-00:04) ...
(00:04-00:08) ...
(00:08-00:12) ...
(00:12-00:15) ... ← 结尾动作要为第二段开头做铺垫
(音效：不用"重低音收尾"，用过渡性音效)

---

【第二段提示词】
参考抖音XX博主【人物】吃【产品】XX。竖屏9:16，15秒，无字幕无台词无背景音乐。
{色调——与第一段完全相同}，{画质——与第一段完全相同}，
{机位——与第一段完全相同}，{场景描述——与第一段完全相同，逐字复制}，
{食物状态描述——可更新，比如"碗里包子少了两个"}，整体氛围XXX。

(00:00-00:04) ... ← 开头动作承接第一段结尾
(00:04-00:08) ...
(00:08-00:12) ...
(00:12-00:15) ... ← 最终收尾
(音效：最后一段才用"重低音收尾定格")
```

## 常见问题

**Q：两段生成出来的人物长得不完全一样怎么办？**
A：这是即梦的已知限制，多段之间人物面部细节会有轻微差异。可以接受，因为视频播放速度快，观众不会逐帧对比。如果差异过大，重新生成该段。

**Q：两段的背景有轻微不同怎么办？**
A：确保场景描述文字完全一致可以最大程度降低差异。如果仍有差异（如家具位置微移、灯光角度微变），可以接受5-10%的漂移。严重不一致时重新生成。

**Q：切分点选在哪里最好？**
A：选在"动作完成+新动作即将开始"的节点。比如"吃完一个包子+即将拿起下一个"，而不是"正在咀嚼中间"。
