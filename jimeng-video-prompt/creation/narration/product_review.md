# 口播·种草推荐型提示词 Skill

## 概述

本skill用于生成"博主主观推荐/种草"类口播带货视频的即梦提示词。核心目标：让观众看完觉得"她真的在用这个东西，真的好用，我也想买"。和功能演示型的区别是——功能演示重在"怎么用"，种草推荐重在"用了感觉有多好"。

典型品类：服装家居服、美妆护肤品、零食饮品、香水、生巧等"体验驱动型"产品。

## L2覆盖声明

- L2-03 台词：**有台词**（台词密度高于功能演示型，核心是主观感受输出）
- L2-04 音色：**使用【音色】**
- L2-02 BGM：**无/有均可**，默认无BGM（用环境底噪+面料/产品触感声营造真实感）
- L2-08 音效：环境底噪+产品触感声（面料摩擦声、包装撕开声、瓶盖声等）
- L2-09 开场：情感/身份钩子开场
- L2-10 收尾：轻度引流

## 核心规则

### 规则1：台词风格——"被产品打动的真情实感"

种草推荐型的台词不是在"介绍产品"，是在"分享自己被打动的感受"。这是本质区别。

**台词的情绪递进结构**：
1. **开场钩子**：用身份认同或情感共鸣起手（不要用产品名/功能起手）
   - ✅「姐妹们这真的不能叫睡衣了，这是我的一层皮呀」
   - ✅「生巧赛道这么多年，就没有超越他们家的吧」
   - ❌「今天给大家推荐一款XX品牌的睡衣」
   
2. **感受输出**：用身体感受描述产品体验（不要用参数/成分堆砌）
   - ✅「穿上身像裸睡一样，整个人都松了」
   - ✅「微苦微甜，完全不会被腻住」
   - ❌「采用100%纯棉面料，40支精梳棉」

3. **细节佐证**：用一个具体的小细节证明"我真的在用"
   - ✅「我跟你说这个我都洗了两水了，团在洗衣机里抖一抖照样不起皱」
   - ✅「你再看这扣子，这袖口的包边，做工真的不像便宜的睡衣」
   
4. **轻度引流收尾**：用态度收尾，不要用促销话术
   - ✅「睡衣不用买贵的，舒服得劲儿就行」
   - ✅「经常吃巧克力的人一定吃得出来，回购率已经说明一切」
   - ❌「点左下小黄车，手慢无」

### 规则2：台词与画面同步——"说什么就看什么"

台词提到的每一个感受点，画面中必须有对应的动作在同时发生。

**对照表**：
| 台词内容 | 画面动作 |
|---|---|
| 说面料/质感 | 手指触摸/捏起面料展示 |
| 说穿上身感受 | 模特转身/展示整体廓形 |
| 说细节做工 | 低头看扣子/袖口/包边+手指摸过 |
| 说洗后效果 | 捏起下摆抖一抖展示平整度 |
| 说味道/口感 | 正在咀嚼/闭眼回味/品味表情 |
| 说流心质感 | 掰开/切开展示流心流淌 |

### 规则3：人物表情——"被产品打动的真实反应"

种草推荐型的表情核心是**"发自内心的喜欢"**，不是"对镜头的标准微笑"。

**关键表情设计**：
- 说到产品好的时候：忍不住笑出来、眉毛上扬眼睛微微睁大
- 展示细节的时候：低头认真看+抬头时带着"你看多好"的笃定
- 体验产品的时候：闭眼感受+表情从惊讶过渡到满足
- 收尾推荐的时候：带着"我真心推荐"的真诚和兴奋

**推荐的表情描述**：
- 「肩膀微微耸了一下表情瞬间被舒适感打动」
- 「嘴角不自觉上扬，然后抬眸看向镜头眼神里带着"你看多好看"的笃定」
- 「说到一半自己也忍不住笑了」
- 「下意识用手背贴了一下脸颊」
- 「低头看袖口像在认真检查做工，抬起头对镜头笃定地点了一下头」
- 「对镜头笑得有点放肆，带着分享好物的真诚兴奋」

### 规则4：客户台词的处理原则

用户经常会提供原始台词（从参考视频中转写的/自己写的/品牌方给的），处理原则：

1. **保留所有卖点**：不能擅自删减用户/客户的卖点，即使觉得"信息密度太大"也只能建议精简，不能直接删
2. **可以做的优化**：口语化调整、错别字修正、按视觉逻辑重新分配（哪句台词配哪个镜头）
3. **可以建议删的情况**：提出建议并说明理由，等用户确认后再删
4. **保留原文金句**：原台词中有记忆点的金句要保留（如"这是我的一层皮""鲜得掉眉毛"）

### 规则5：多语言口播

当用户要求非中文台词时（如泰语、英语、日语）：
- 台词内容按用户给的翻译原文使用目标语言
- 口播台词用目标语言书写，不加中文翻译在提示词内
- 其他所有描述（镜头、动作、音效）仍用中文
- 如果AI不确定目标语言的准确性，需提醒用户让母语者校对

## 15s以上（30s）种草推荐的结构

30秒 = 2×15秒，按以下节奏分配：

**第一段（0-15s）**：产品初印象
- 开场钩子（品牌地位/情感共鸣）
- 撕包装/开箱（仪式感）
- 产品视觉高潮（掰开流心/展示面料/试色等）

**第二段（15-30s）**：深度体验
- 实际使用/上身/入口
- 细节佐证（做工/口感层次/洗后效果）
- 进阶用法（如微波炉加热/搭配穿法）
- 轻度引流收尾

多段衔接规则见 `creation/multi_segment/continuity_rules.md`。
