# 沉浸式吃播提示词 Skill

## 概述

本skill用于生成沉浸式无台词吃播类视频的即梦提示词。核心目标：让观众看完流口水、想下单。不是拍广告，是拍"一个人真正在享受美食"的状态。

## L2覆盖声明

本类型对L2默认值的覆盖：
- L2-03 台词：**无台词**（但可有极少量语气词，如简短介绍"这是活珠子，南京老味道，鲜得掉眉毛"级别的一句话也允许）
- L2-04 音色：**不使用【音色】**
- L2-08 音效：**强制使用音效三件套**（详见 `rules/L2_defaults.md` 音效三件套章节）

## 提示词结构模板（v2.0电影级格式）

### 头部信息块
```
写实真人风格，8K超高清，竖屏9:16。无字幕无台词无背景音乐。
{色调描述}，{光源描述}。iPhone原相机真实拍摄感。

【人物】{服装/发型/状态描述}。
【场景】{场景类型+具体细节描述}。若使用【背景】槽位则只描述人物与背景的位置关系+光效交互。深景深f/8全部清晰入镜（车内/街边场景必备）。
【产品】{食物名称}，{初始状态描述（如装在塑料袋/放在桌上）}。

整体氛围{氛围词}沉浸ASMR。
```

### 分镜描述块（标准四层结构）
```
[时间码], {景别/运镜/景深}
动作描述：{主体}+{动作六维度拆解}+{食物状态变化}。
情绪描述：眼神{移动轨迹}+表情{眉毛/嘴角变化}+{情绪词}。
环境描述：{场景具体细节（车内座椅/街边店铺/光影效果）}。
(音效：
  [环境层] {场景环境音}
  [食物层] {食物专属音效}
  [人物层] {咀嚼声+吸口水声+满足声}
)
```

**注意**：所有时间码使用方括号 `[]`，粒度为2-3秒/分镜。

## 电影级镜头语言应用

### 沉浸式吃播的镜头语言选择

**首选镜头组合**：
- **固定机位** 为主（突出食物和咀嚼动作本身，避免运镜干扰）
- **特写/大特写** 占60%（食物细节/咀嚼瞬间）
- **半身中景** 占30%（建立场景/展示人物状态）
- **偶尔缓推** 10%（从中景推至特写，制造情绪递进）

**景深控制**：
- **深景深f/8**：车内/街边场景（展示环境细节：真皮座椅/店铺招牌）
- **浅景深f/2.8**：食物特写（虚化背景，突出食物质感）

**光影控制**：
- **侧光45度**：立体感最强，食物质感最佳
- **顶光+侧光组合**：午后自然光从车窗照入的效果
- **避免逆光**：食物会过暗

**运镜禁区**：
- ❌ 避免过度运镜（横摇/环绕/升降）
- ❌ 避免快速推拉（破坏沉浸感）
- ✅ 固定机位 + 偶尔缓推即可

## 构图类型选择

沉浸式吃播有两种主流构图，根据用户需求选择：

### 构图A：传统半身构图（人物为主，产品为辅）
- **适用场景**：强调"人在享受美食"的状态，适合车内场景、街边场景
- **机位**：半身中景偏下仰角固定机位（镜头在胸口高度往上拍）
- **人物占比**：50-60%（画面上方）
- **产品占比**：30-40%（画面下方1/3处）
- **产品形态**：单个/手持
- **背景处理**：清晰入镜，展示场景细节（车内/街边烟火气）
- **典型案例**：车内吃包子、街边吃鸡爪

### 构图B：产品俯拍构图（产品为主，人物为辅）
- **适用场景**：需要突出产品视觉冲击力，适合"一盘/一堆"产品的展示
- **机位**：俯拍特写固定机位（镜头从上往下45度角拍摄）
- **人物占比**：10-15%（画面右上角或左上角，仅露嘴部）
- **产品占比**：70-80%（画面中下方主体）
- **产品形态**：一盘堆叠/多个
- **背景处理**：可虚化，突出产品主体
- **典型案例**：一盘酱肉包、一盆小龙虾、一堆鸡爪
- **详细规则**：见 `templates/immersive_eating/baozi_product_centered.md`

### 如何判断用户需要哪种构图？

**识别信号词**：
- "镜头对着嘴巴" / "脸部很小" / "突出产品" / "产品为中心" → **构图B**
- "人物在角落" / "产品占大部分" / "一盘/一堆" → **构图B**
- "车内场景" / "街边场景" / "沉浸式享受" / 无特殊要求 → **构图A**

**用户痛点识别**：
- "脸部太大，产品太小" → 当前用的是构图A但需要构图B
- "产品看不清" → 需要调整为构图B或增加产品特写镜头

## 核心规则

### 规则1：动作循环原则

沉浸式吃播的核心不是"起承转合"的叙事结构，而是**两个关键动作的反复循环**。每种食物都有自己的"两个关键动作"：

| 食物类型 | 关键动作A | 关键动作B |
|---|---|---|
| 包子类 | 双手撕开包子见内馅/汤汁 | 大口咬下咀嚼 |
| 鸡爪类 | 双手掰开鸡爪见骨节/筋膜 | 咬下连骨带肉咀嚼 |
| 贝类 | 掰开贝壳（有阻力感+"噌"声） | 剥出蛤肉送入口中咀嚼 |
| 活珠子 | 磕蛋壳→剥开见活珠子 | 小口咬下咀嚼+顺带吸汤汁 |
| 西瓜/水果 | 咬下果肉汁水喷溅 | 汁水流下/滴落到桌面/座椅 |
| 面食/粉丝 | 筷子挑起高高举起拉丝 | 吸溜入口大口咀嚼 |
| 酥皮/炸物 | 咬下酥皮咔嚓碎裂 | 连皮带肉/馅大口咀嚼 |
| 流心类甜品 | 掰开/切开见流心流淌 | 送入口中咀嚼 |

**15秒内，A和B至少各出现2次，形成A→B→A→B的循环节奏。**

### 规则2：食物适配色调

不同食物类型使用不同色调，不可千篇一律：

| 食物类型 | 推荐色调 |
|---|---|
| 热食/油润系（火鸡面、烧烤、火锅、红油鸡爪） | 暖黄高饱和 |
| 冷食/清爽系（寿司、沙拉、水果、冰镇饮品） | 清透冷绿 或 暖白清透 |
| 甜品/烘焙系（蛋糕、面包、巧克力） | 暖粉柔光 或 暖白柔光 |
| 中式家常（包子、饺子、凉皮） | 暖黄自然光 |
| 海鲜系（文蛤、小龙虾、螃蟹） | 暖黄高饱和 |

### 规则3：食物动态细节——每种食物必须有专属的"视觉爆点"

不同食物的"让人流口水"的关键视觉细节完全不同，不可套模板：

- **包子类**：酱汁从掰开处涌出流淌、热气从内馅处升腾
- **鸡爪类**：骨节断裂白骨暴露、筋膜拉丝、红油酱汁裹着辣椒碎从断口滴落
- **贝类**：贝壳紧闭有阻力→"噌"一声弹开、蛤肉干净饱满无汤水紧贴壳内
- **活珠子**：蛛网状裂纹磕开、温热汤汁在裂口处渗出
- **西瓜**：牙齿切入瓜肉汁水喷溅、红色汁水顺下巴滴落
- **面食/粉丝**：筷子高举粉丝缓缓垂落拉长、浓汤沿面条/粉丝往下淌
- **酥皮类**：牙齿咬穿酥皮瞬间的咔嚓碎裂、酥皮碎片从嘴角掉落
- **流心甜品**：掰开/切开瞬间巧克力/奶黄从中间缓缓流淌、两半之间拉丝

### 规则4：人物表情——"真正在享受美食"而不是"在表演吃东西"

**核心原则**：表情是对食物味道的真实反应，不是对镜头的表演。

**必须做到的**：
- 眼神自然下垂看食物，不是一直盯着镜头
- 眼睛随动作移动：看食物→闭眼品味→睁眼看下一个
- 闭眼咀嚼时的表情变化：眉头微皱（被味道击中）→舒展（回味满足）
- 嘴角有无意识的满足微笑（不是刻意笑）
- 吃到好吃的时候头微微后仰或侧歪（本能反应）

**严格禁止的**：
- 全程直视镜头不移开眼神
- 标准化"带货微笑"
- 夸张到不真实的表情反应
- "温柔直视镜头嘴角微扬"这类摆拍式描述

**推荐的表情描述词汇**：
- 「眼睛自然闭上开始慢慢咀嚼」
- 「眉头先微微皱起然后完全舒展开，整个人沉浸在酥脆口感里」
- 「眼睛半闭半睁像在品味」
- 「整个表情是被好吃的东西征服了的放松状态」
- 「嚼着嚼着嘴角不自觉带出一个满足的微笑」
- 「头微微后仰靠在座椅头枕上，整个人放松享受」

### 规则5：场景设计——生活化真实场景，降低AI感

**核心原则**：场景越具体、越生活化，AI感越低。避免"虚化背景+特写"的组合，这会加重AI的不真实感。

**车内场景规范（已固定）**：
- 机位：半身中景偏下仰角固定机位（镜头在胸口高度往上拍）
- 人物占画面上方60%，头顶留空能看到车顶（星空灯/氛围灯/车顶内饰）
- 食物在画面下方1/3处
- 车内环境全部清晰入镜：真皮座椅颜色+品牌标识（RR/奔驰/保时捷等）+车窗外街景/店铺招牌清晰可见
- 食物的承载方式要真实：锡纸托盘放腿上、白色打包塑料袋、一次性餐具、泡沫碗
- 制造反差感：豪车配市井美食（这是流量密码）

**街边/店铺场景规范**：
- 背景环境全部清晰入镜：店铺招牌+玻璃窗内蒸笼/厨房+门口来往路人和电瓶车+自然光线
- 食物承载方式：塑料袋、纸碗、一次性筷子
- 环境细节要有烟火气：排队人群、老板忙碌的身影、蒸笼热气

**需要避免的场景描述**：
- ❌「背景大面积虚化仅保留模糊暖光氛围」
- ❌「纯色简约背景」
- ❌「广告棚柔光场景」
- ✅「劳斯莱斯后座米色真皮座椅+车顶星空灯+车窗外夜市街边店铺招牌霓虹灯清晰可见」
- ✅「北京街边早餐店门口红色招牌+玻璃窗里面能看到蒸笼冒着热气+门口塑料凳子」

### 规则6：音效设计——三件套必备

详见 `rules/L2_defaults.md` 中"沉浸式吃播·音效三件套"章节。此处补充食物专属音效对照表：

| 食物类型 | 专属音效关键词 |
|---|---|
| 包子 | 包子皮撕开柔软声、酱汁流动湿润声、热气升腾声 |
| 鸡爪 | 骨肉撕扯声、脆骨咬合咔嚓声、骨节掰断清脆声、筋膜撕裂拉丝声 |
| 贝类 | 贝壳阻力摩擦声、掰开瞬间"噌"弹开脆声、蛤肉剥离声 |
| 活珠子 | 蛋壳磕裂清脆声、汤汁渗出湿润声、蛋壳剥落声 |
| 西瓜 | 牙齿咬入瓜肉清脆咔嚓声、汁水喷溅声、汁水滴落座椅/桌面声 |
| 面食/粉丝 | 粉丝吸溜入口声、浓汤滴落声、筷子碰碗声 |
| 脆皮/酥皮 | 酥皮咬碎极脆咔嚓声、酥皮碎片掉落声、手指弹酥皮敲击声 |
| 锅包肉 | 酱汁滴落湿润声、炸壳咬碎酥脆声、筷子翻搅打包盒声 |
| 流心甜品 | 糯米皮拉伸声、巧克力流淌湿润声、脆珠咬合细微脆响 |
| 绿豆沙/冰饮 | 杯盖揭开声、冰块碰撞声、浓稠液体入口吞咽声 |
| 荔枝/水果 | 果壳撕裂清脆声、果肉咬合爆汁声 |

### 规则7：收尾定式

沉浸式吃播的收尾有固定模式：
- 模特处于满足享受的咀嚼状态
- 嘴角带着无意识微笑或食物残渍/油光
- **手已经伸向下一个/下一块/碗里**（暗示"停不下来"，比任何台词都有说服力）
- 音效以"一声拉长的满足'嗯——'+重低音收尾"结束

**不使用任何引流话术收尾**（如"点小黄车""手慢无"等）。沉浸式吃播的收尾目标是让观众"馋到自己去搜"，而不是"被催促去下单"。

## 完整提示词生成流程（v2.0电影级格式）

收到用户指令后，按以下步骤生成：

### Step 1：识别食物类型和关键动作
从用户给的食物名称/图片中判断：
- 属于上述哪种食物类型
- 对应的关键动作A和B是什么
- 对应的专属音效关键词是什么
- 对应的色调是什么

### Step 2：识别场景和构图
从用户指令中判断：
- 场景：车内/街边/其他
- 构图：构图A（人物为主）还是构图B（产品为主）
- 景深：深景深f/8（展示环境）还是浅景深f/2.8（突出食物）

### Step 3：设计分镜节奏（5-7个分镜）
15秒视频的标准分镜节奏：
```
[0-3秒]：开场建立（拿起食物+展示完整形态）{半身中景/固定机位/景深f/8}
[3-5秒]：关键动作A特写（撕开/掰开）{特写/固定机位/景深f/2.8}
[5-8秒]：关键动作B（咬下咀嚼）{大特写/固定机位}
[8-11秒]：关键动作A重复（继续撕/掰）{特写/缓推至大特写}
[11-13秒]：关键动作B重复（咀嚼享受）{半身中景/固定机位}
[13-15秒]：收尾定式（满足+手伸向下一个）{半身中景/固定机位/景深f/8}
```

### Step 4：逐镜填充四层描述
按照标准四层结构逐个填充：

```
[时间码], {景别/运镜/景深}
动作描述：{主体}从{起点}→{终点}，{速度}{力度}{动作}。{食物状态变化（酱汁流淌/热气升腾等）}。
情绪描述：眼神{从哪到哪}，{眉毛/嘴角}变化，整个表情是{情绪词}状态。
环境描述：{车内具体细节/街边烟火气/光影效果}。
(音效：
  [环境层] {场景环境音}
  [食物层] {食物专属音效（撕裂声/咀嚼声等）}
  [人物层] {吸口水声/满足嗯声}
)
```

### Step 5：确保动作循环和情绪弧光
- **动作循环**：关键动作A和B各出现至少2次，形成A→B→A→B循环
- **情绪弧光**：期待（0-3秒）→ 瞬间满足（3-8秒）→ 享受回味（8-13秒）→ 停不下来（13-15秒）

### Step 6：质量自检清单
生成完毕后检查：

**格式检查**：
- [ ] 时间码使用方括号 `[]` 而非圆括号
- [ ] 时间粒度为2-3秒/分镜
- [ ] 每个分镜包含四层（镜头/动作/情绪/环境/音效）
- [ ] 镜头语言用 `{}`，音效分层标注 `[环境层][食物层][人物层]`

**内容检查**：
- [ ] 字符数在2000以内
- [ ] 无跨段引用词
- [ ] 音效三件套齐全（咀嚼声+吸口水声+嗯声）且分布在不同分镜
- [ ] 关键动作A和B各出现至少2次
- [ ] 食物专属视觉爆点细节完整（酱汁流淌/热气升腾/骨节断裂等）
- [ ] 收尾使用收尾定式

**专业度检查**：
- [ ] 动作拆解到位（六维度：身体部位/起点终点/速度/力度/位置/附加动作）
- [ ] 情绪描述有弧光（眼神移动+表情变化+情绪词，非"很开心"等抽象词）
- [ ] 场景具体生活化（车内座椅logo/街边店铺招牌，非"虚化背景"）
- [ ] 镜头语言专业（固定机位为主+景深控制+光影描述）
- [ ] 人物表情自然（眼神自然下垂看食物，非直视镜头摆拍）

## 完整案例示例（v2.0电影级格式）

### 示例：酱肉包·车内场景（15秒）

**头部信息块**：
