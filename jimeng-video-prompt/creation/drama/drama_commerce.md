# 剧情带货视频提示词 Skill

## 概述

本skill用于生成剧情带货（软广）类视频的即梦提示词。核心目标：让观众在60秒内完成"被剧情吸引→情绪被调动→对产品产生好感→产生购买冲动"的完整转化链路。产品不是主角，剧情才是主角——产品在剧情的反转点或情感高潮处自然出现。

典型形式：婆媳争斗、职场打脸、前任重逢、闺蜜反目、亲子温情等短剧，产品作为关键道具串联剧情。

## L2覆盖声明

本类型对L2默认值的覆盖：

- L2-01 人物外貌：**主角不描述（通过【人物】给图），非主角（导购/路人/配角等无参考图的角色）可用一行文字描述基本外貌以区分角色**
- L2-02 BGM：**第一二幕无BGM（纯环境音+动作音效增强真实感），第三幕起可加轻柔情感BGM（钢琴/弦乐），第四幕切为轻快活泼BGM**
- L2-03 台词：**有台词/多角色对白**
- L2-04 音色：**使用【音色】**
- L2-05 性别标注：**按角色需要标注**
- L2-06 人物数量：**多人（通常2-4人）**
- L2-08 音效：**环境音+动作音效+情绪音效（详见规则5）**
- L2-09 开场：**冲突/悬念开场（详见规则1·黄金3秒法则）**
- L2-10 收尾：**第三幕情感升华+第四幕产品展示引流**
- L2-11 场景：**可风格化，不限于生活化真实场景（超市/海边/办公室/街头等均可）**

## 提示词结构模板（v2.0电影级格式）

剧情带货为多段视频（通常4段×15s=60s），每段提示词格式：

### 头部信息块
```
写实真人风格，8K超高清，竖屏9:16。中文台词无字幕。
{音效/音乐设定（按幕分层）}。人物一致，动作丝滑。
{色调描述}。

【人物】{主角A}：【人物】{服装/发型/状态}。
       {主角B}：【人物】{服装/发型/状态}。
       {配角C（无需槽位）}：{外貌/服装/角色定位}。
【场景】{场景类型+关键细节}。

【整体氛围】{情绪调性}。
```

### 分镜描述块（标准四层结构）
```
[时间码], {景别/运镜/景深}
动作描述：{角色}+{动作六维度}+{肢体语言/微表情}。{角色}（语气标注）：「台词内容」
情绪描述：{角色}眼神{变化}+表情{从...到...}+整个状态是{情绪词}。
环境/氛围：{场景细节/光影/围观者反应/气氛营造}。
(音效：
  [环境层] {场景环境音}
  [动作层] {动作/冲突音效}
  [情绪层] {呼吸/吞咽/气势声}
  [BGM] {按幕是否有BGM}
)
```

**注意**：所有时间码使用方括号 `[]`，粒度为2-4秒/分镜（剧情类节奏可比其他类型稍快）。

## 电影级镜头语言应用

### 剧情带货的镜头语言选择

**首选镜头组合**（服务于情绪而非产品细节）：
- **固定机位双人中景** 40%（对话场景，展示关系）
- **正反打特写** 30%（对话中切换脸部特写）
- **推镜** 20%（情绪递进/威压感/反转瞬间）
- **跟镜/摇镜** 10%（跟随走动/转头甩镜）

**景别分配**：
- **中景**：建立人物关系（对峙/并肩/拥抱）
- **近景/特写**：捕捉情绪变化（眼神/表情/微表情）
- **大特写**：情绪爆发瞬间（眼眶泛红/咬唇/愤怒）

**运镜情绪对应**：
- **冲突对话**：固定机位中景 → 正反打特写切换
- **被欺负委屈**：特写面部 + 轻推镜（放大无助感）
- **反转爆发**：快推镜（护短者脸从平静到愤怒）+ 甩镜（转头瞬间）
- **打脸瞬间**：对手后退特写 + 围观者反应快切
- **温情**：中景双人 + 缓推至近景
- **产品展示**：固定机位半身中景 + 产品特写

**景深控制**：
- **浅景深f/2.8**：虚化背景突出人物情绪（温情/独白）
- **中景深f/5.6**：保留环境氛围（超市/办公室/街头）
- **深景深f/8**：展示围观群众反应（打脸场景）

**光影控制**（情绪营造）：
- **冲突场景**：硬光/对比强烈/阴影清晰（紧张感）
- **反转瞬间**：侧光45度/轮廓光（气势感）
- **温情场景**：柔光/暖色调/光线柔和（治愈感）
- **产品展示**：柔光均匀/无阴影（清晰专业）

**切换方式**：
- 对话中：硬切（快节奏对峙）
- 情绪转折：溶解/淡入淡出（时间流逝/情绪转换）
- 打脸瞬间：卡点硬切配合鼓点（爽感最强）

## 核心规则

### 规则1：万能四幕结构

所有剧情带货视频遵循以下四幕结构，每幕对应一个15秒段：

| 幕 | 功能 | 观众情绪目标 | 产品状态 |
|---|---|---|---|
| 第一幕·冲突建立 | 3秒内抓住注意力，建立核心冲突 | 好奇/紧张/心疼/愤怒 | 出现但被"否定"或"误解" |
| 第二幕·反转爆发 | 矛盾推到最高点后180度反转 | 从愤怒/紧张→瞬间爽感/感动 | 在反转中被"正名"或"证明价值" |
| 第三幕·情感升华 | 利用反转余温制造共鸣/感动 | 感动/温暖/认同 | 自然融入情感高潮场景 |
| 第四幕·产品转化 | 从情感无缝过渡到产品展示 | 好感拉满+行动冲动 | 正面特写+卖点口播+引导下单 |

**第一幕的黄金3秒法则**——前3秒决定观众划走还是留下，必须用以下方式之一开场：

| 开场类型 | 示例台词 | 适用品类 |
|---|---|---|
| 冲突对话 | "这种便宜货也配碰？" | 日用/食品/家居 |
| 反常行为 | 女主当众把贵妇面霜扔进垃圾桶 | 护肤/美妆 |
| 情感冲击 | 孩子哭着说"妈妈你为什么不给我买" | 母婴/食品 |
| 身份冲突 | 穿工装的弟弟走进哥哥的豪华饭局 | 服装/鞋包 |
| 打脸预告 | "你等着，今天让你知道什么叫好东西" | 所有品类 |

### 规则2：产品三次出现法则

产品在剧情中必须出现**至少三次**，每次功能不同：

```
第一次（第一幕）：被否定/被误解/被嫌弃
→ 制造冲突，让观众好奇"这东西到底好不好"

第二次（第二幕或第三幕）：被正名/被证明/被认可
→ 反转瞬间产品获得情感加持，观众情绪最高点

第三次（第四幕）：正面展示+卖点口播
→ 好感已拉满，此时展示=临门一脚
```

**严格禁止**：产品在第一幕就被夸/被推荐——没有"被否定"就没有"被正名"的爽感。

### 规则3：台词密度铁律

即梦15秒一段的实际台词容量有严格上限：

```
每段15秒最多：
- 4-5句短台词（每句5-10字）
- 或3-4句中等台词（每句10-15字）
- 或2句长台词（每句15-20字）+1句短台词

每段最多3-4个分镜

绝对不要：
- 一段塞超过6句台词
- 一段超过5个分镜
- 角色说超过20字的单句
- 内心独白占用台词位（除非极必要，否则转化为对话或动作）
```

### 规则4：多角色对话分配

剧情类通常有2-4个角色，台词分配原则：

| 角色类型 | 台词功能 | 每段台词量 |
|---|---|---|
| 主角（被欺负/被误解的一方） | 委屈→反击→展示 | 第一幕1-2句委屈，第三四幕2-3句 |
| 对手（制造冲突的一方） | 挑衅→嚣张→被打脸 | 第一二幕2-3句，后面基本没台词 |
| 护短者（替主角出头的人） | 沉默→爆发→温情 | 第二幕2-3句爆发，第三幕1-2句温情 |
| 权威者（经理/老板/长辈） | 仲裁/定性 | 第二幕1句定性即可 |

**核心原则**：每段内不超过2个角色在说话。三个人同时说话观众会乱。

### 规则5：音效与BGM设计

剧情类视频的音频设计按幕分层：

| 幕 | BGM | 音效重点 |
|---|---|---|
| 第一幕 | 无BGM | 环境底噪（超市广播/街道车流/办公室键盘）+ 动作音效（脚步/放东西/拉链）+ 冲突音效（拍桌/摔东西） |
| 第二幕 | 无BGM | 反转瞬间的"气势音效"（转头时气势声、逼近脚步、围观窃窃私语）+ 打脸时的短促鼓点 |
| 第三幕 | 轻柔钢琴/弦乐BGM起 | 情感音效（抽泣声/拍后背声/风声）+ BGM渐强到情绪高潮 |
| 第四幕 | 切为轻快活泼BGM | 产品相关ASMR音效（开盖声/喷雾声/撕包装声/面料声）+ 收尾叮咚提示音 |

**关键**：第一二幕不加BGM是刻意的——纯环境音+对话的"纪录片感"让冲突更真实，BGM在第三幕温情时才进入，对比之下情感冲击更强。

### 规则6：镜头语言

剧情类的镜头逻辑与带货类完全不同——服务于"情绪"而非"产品细节"：

| 情绪节点 | 推荐镜头 |
|---|---|
| 冲突对话 | 中景双人构图（展示两人对峙关系）→ 特写切换（A说话切A脸，B说话切B脸） |
| 被欺负的委屈 | 特写主角面部（低头、咬唇、眼眶泛红） |
| 反转爆发 | 护短者的脸从平静到愤怒的推镜 + 转头瞬间的甩镜/极速推镜 |
| 打脸瞬间 | 对手后退/愣住的特写 + 围观者反应的快切 |
| 温情 | 中景双人构图（拥抱/握手/并排）+ 暖色调 |
| 产品展示 | 跟带货类一致：中景持产品口播 → 特写微距产品细节 → 包装定格 |

**每段不超过4个镜头切换**（3个最佳），让即梦自己处理镜头间的过渡。

### 规则7：六大品类剧情模板速查

| 品类 | 推荐剧情类型 | 冲突核心 | 反转方式 |
|---|---|---|---|
| 日用品 | 家庭关系反转（婆媳/夫妻） | "便宜货不配用" | 护短者正名"她选的就是好的" |
| 护肤美妆 | 职场/社交打脸 | "你皮肤/妆容太差了" | 使用后惊艳全场 |
| 食品零食 | 试吃真香反转 | "包装丑/杂牌能好吃？" | 尝一口→真香→抢着吃 |
| 服装鞋包 | 身份反转/变装逆袭 | "穿得像XX""配不上这个场合" | 换装后惊艳/导购态度180°转变 |
| 数码电子 | 实力碾压/效率对比 | "杂牌能比得上大牌？" | 现场PK碾压→对方主动问哪买的 |
| 母婴儿童 | 亲子温情/保护孩子 | "太惯着了/没必要" | 家长看到孩子委屈后坚定要买 |

### 规则8：十条禁忌

1. 不要让产品在第一幕就被夸——必须先被否定才有反转
2. 不超过4个角色——15s×4段容不下太多人
3. 第一二幕产品是"道具"不是"主角"——植入感不能太强
4. 第三幕不开始口播卖点——第三幕是情感段不是广告段
5. 不用"这个产品真的很好"这种直白台词——用角色行为证明（抢着吃/追问哪买的）
6. 反转不能拖到第三幕——第二幕30秒处必须反转
7. 冲突不能太严重——轻喜剧冲突最佳（嫌弃/误解/争抢），不做暴力/犯罪
8. 结局必须正向——观众心情好才会下单
9. 最后3秒必须有行动号召——"链接在下方/同款/点击购买"
10. 不要一段塞超过5句台词——宁可删台词加表情动作

## 完整提示词生成流程（v2.0电影级格式）

### Step 1：确认产品信息

必须获取以下三项才能开工：
- 产品名称
- 核心卖点（1-3个）
- 目标人群

可选项：价格区间、希望的剧情风格、特殊要求。

### Step 2：匹配剧情模板

根据产品品类查规则7的模板速查表，确定：
- 推荐剧情类型
- 冲突核心
- 反转方式

### Step 3：设计四幕剧本

按规则1的四幕结构编写剧本，同时检查：
- 产品是否出现了三次（规则2）
- 开场前3秒是否有冲突钩子（规则1·黄金3秒）
- 每段台词是否超量（规则3）

### Step 4：为每幕设计分镜节奏

每幕（15秒）的标准分镜：
```
第一幕（冲突）：
[0-3]：冲突开场钩子 {中景双人/固定机位}
[3-6]：矛盾升级 {特写切换/正反打}
[6-9]：产品被否定 {近景/固定机位}
[9-12]：委屈/愤怒情绪 {特写面部/轻推镜}
[12-15]：悬念埋伏 {中景/固定机位}

第二幕（反转）：
[0-4]：矛盾推至顶点 {特写/固定机位}
[4-7]：反转瞬间 {快推镜/甩镜}
[7-11]：打脸瞬间 {特写切换/卡点硬切}
[11-15]：围观反应 {中景/横摇}

第三幕（情感）：
[0-4]：情感转折开始 {中景双人/缓推}
[4-9]：情感深化 {近景/固定机位}
[9-15]：情感高潮 {特写/浅景深虚化}

第四幕（转化）：
[0-5]：产品展示开场 {半身中景/固定机位}
[5-10]：产品特写细节 {特写/缓推至大特写}
[10-15]：包装定格+行动号召 {特写/固定机位}
```

### Step 5：逐镜填充四层描述

按照标准四层结构（镜头/动作+台词/情绪/环境/音效）逐个填充。

**冲突对话示例**：
```
[00:00-00:03], {中景双人对峙构图/固定机位/景深f/5.6}
动作：海边停车场，新女友下车后上下打量女主，双手抱胸站在跑车旁。女主（被冷场面对视）：「……」新女友（挑衅）：「就这么出去？不怕晒成黑炭？」
情绪：新女友眼神从上到下扫视女主，嘴角带嘲讽弧度，眉毛挑起显优越感。女主眼神从平视转为低垂回避，嘴唇微抿，整个状态是被挑衅的不自在。
环境：午后烈日海边停车场，蓝天白云，远处金色沙滩和海面，跑车在背景中清晰可见。
(音效：
  [环境层] 海浪远处拍岸+海风呼呼+海鸥叫声
  [动作层] 高跟鞋踩地声+车门关闭声
  [情绪层] 新女友嗤笑鼻音+女主吞咽紧张声
  [BGM] 无
)
```

### Step 6：确保四幕情绪弧光

- **第一幕**：好奇/紧张/心疼（冲突建立）
- **第二幕**：从愤怒→瞬间爽感（反转打脸）
- **第三幕**：感动/温暖/认同（情感升华）
- **第四幕**：好感拉满+购买冲动（产品转化）

### Step 7：质量自检清单

**格式检查**：
- [ ] 时间码使用方括号 `[]`
- [ ] 时间粒度为2-4秒/分镜
- [ ] 每个分镜包含四层（镜头/动作+台词/情绪/环境/音效）
- [ ] 台词用「」标注，并标注角色名和语气

**内容检查**：
- [ ] 每段字符数在2000以内
- [ ] 产品在第一幕被否定
- [ ] 第二幕有反转
- [ ] 产品出现至少三次（否定→正名→展示）
- [ ] 每段台词不超过5句短台词
- [ ] 每段分镜不超过4个
- [ ] 无跨段引用词
- [ ] 第一二幕无BGM，第三幕起有BGM
- [ ] 最后3秒有行动号召

**专业度检查**：
- [ ] 镜头语言服务于情绪（推镜/正反打/甩镜）
- [ ] 情绪弧光完整（冲突→反转→温情→转化）
- [ ] 音效按幕分层设计
- [ ] 台词密度合理（不超载）
- [ ] 结局正向积极

## 完整案例示例（v2.0电影级格式）

### 示例：防晒喷雾·前任重逢·海边反转（60秒）

**产品信息**：
- 产品：防晒喷雾（SPF50+ PA++++）
- 核心卖点：防水防汗、轻薄不黏腻、持久防护
- 价格：便宜（二十几块）
- 剧情类型：前任重逢·新旧女友对比

**四幕结构**：
