# 反推·输入模式B：截图/文字输入

## 适用场景

用户给了以下任意组合的输入：
- 视频截图（1-N帧）
- GPT/其他AI生成的分镜图（带时间码和动作说明的多帧图）
- 文字描述（"这个视频大概是..."）
- 台词翻译文字（如泰语视频的中文翻译）

## 适用环境

所有环境均可使用（Claude.ai/CC/Codex/Gemini），无需bash工具。

---

## 处理流程

### 情况1：用户给了视频截图（无文字说明）

**处理步骤**：
1. 分析每帧截图的内容：人物动作、表情、产品状态、场景环境、光线色调
2. 根据截图数量和内容变化推断分镜结构和时间分配
3. 判断视频类型（沉浸式/口播/剧情）
4. 进入V3反推流程的Step 2-5

**信息补全**：截图无法提供的信息需要合理推断或向用户确认：
- 音效（截图无声音信息）→ 根据食物类型/产品类型推断
- 台词（截图看不出是否有口播）→ 问用户"这个视频有台词吗"
- 分镜时长（截图无时间信息）→ 默认按15秒均分，或问用户

### 情况2：用户给了AI生成的分镜图（如GPT的10帧/12帧编排图）

**处理步骤**：
1. 分镜图已经包含了时间码、动作说明、分镜顺序——直接读取
2. 不需要重新做6维度拆解，因为分镜图本身就是拆解结果
3. 只需要**补充分镜图无法传达的信息**：
   - 色调/画质风格
   - 音效设计
   - 整体氛围
   - 即梦格式规范（素材槽位、字符限制等）
4. 输出精简的辅助提示词（不是完整分镜重写）

**辅助提示词的格式**：
```
参考图为{内容描述}的{N}个分镜连贯流程，按图中顺序生成视频。

{时长}秒，竖屏9:16，{画质风格}，{色调}，无字幕无背景音乐，{氛围}。

模特按图中顺序：{一句话串联所有分镜的动作}。

{动作/节奏的补充说明}。

(音效：{完整音效描述})
```

### 情况3：用户给了截图+台词文字

**处理步骤**：
1. 截图用于分析视觉层面（动作、场景、色调）
2. 台词文字用于填充①人物（口播部分）
3. 如果台词是翻译文字（如"下面是泰语翻译"），需要将翻译还原为目标语言台词
4. 进入V3反推流程

### 情况4：用户只给了文字描述

**处理步骤**：
1. 根据文字描述判断视频类型
2. 提取描述中的关键信息（食物类型、场景、动作、台词等）
3. 如果信息不足以完成反推，向用户确认缺失信息
4. 进入V3反推流程，缺失维度用合理默认值填充

---

## 信息优先级

当多种输入同时存在时的信息优先级：

1. **用户明确说的** > 一切（如"背景要虚化"即使截图中背景清晰）
2. **截图/分镜图中看到的** > AI的推断
3. **台词原文** > AI的改写（除非用户要求优化）
4. **AI根据类型规则的推断** > 通用默认值

---

## 注意事项

1. **不要过度解读截图**：截图分辨率可能不高，不要对模糊区域做过于细致的分析
2. **帧数少时要保守**：如果用户只给了1-2帧，不要强行推断完整的15秒分镜结构，先问用户要更多帧或文字说明
3. **分镜图已有描述时不要重写**：如果GPT等已经给出了详细的分镜文字描述，辅助提示词只补充即梦需要但图/文字未提供的信息
