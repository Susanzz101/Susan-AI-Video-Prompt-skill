# V3 反推核心规则（v2.0帧级复刻版）

## 概述

本skill用于从现有视频/截图中反向推导出即梦提示词。V3在原V2（6维度拆解→组装→精简）基础上增加了：
1. **类型适配过滤层**：根据目标视频类型自动调整维度权重
2. **帧级复刻能力**（v2.0新增）：以**一秒2帧**的密度（15秒视频=30帧）进行关键帧识别和逐帧描述

## 反推模式

### 模式选择
反推支持两种精度模式，根据用户需求选择：

| 模式 | 精度 | 适用场景 | 输出格式 |
|---|---|---|---|
| **分镜级反推** | 2-3秒/分镜（15秒=5-7个分镜） | 快速复刻、理解视频结构 | 标准四层描述 |
| **帧级反推** | 0.5秒/帧（15秒=30帧） | 精确复刻、秒级还原 | 帧级精简描述 |

**识别信号**：
- 用户说"反推""复刻""拆解" → 默认**帧级反推**
- 用户说"快速理解""大概结构" → 分镜级反推

### 输入模式
无论哪种精度，都支持两种输入：
- **模式A**：用户给了视频文件 → 见 `reverse/input_mode_a.md`
- **模式B**：用户给了截图/帧图/文字描述 → 见 `reverse/input_mode_b.md`

## 帧级反推流程（v2.0核心）

### Step 1：视频类型识别

在开始拆解之前，先判断视频属于哪种类型：

| 类型 | 识别信号 |
|---|---|
| 沉浸式吃播 | 无台词、大量咀嚼镜头、食物特写、ASMR音效 |
| 沉浸式非食品 | 无台词、服装/产品展示、模特pose、卡点换装 |
| 口播功能演示 | 有台词、产品操作步骤演示、痛点开场 |
| 口播种草推荐 | 有台词、博主主观感受输出、产品体验展示 |
| 剧情类 | 有剧情/对话、多人物、冲突/反转 |

类型识别结果决定后续的维度权重和关键帧识别策略。

### Step 2：关键帧识别（30帧全覆盖）

按照**一秒2帧**的密度，对15秒视频识别30个关键帧时刻。

#### 关键帧识别原则

**帧的定义**：画面状态发生显著变化的时刻，包括：
1. **动作变化**：手从A位置移到B位置、嘴巴从闭到张、产品从静止到移动
2. **表情转折**：眉毛从舒展到皱起、眼睛从睁到闭、嘴角从平到笑
3. **产品状态**：包子从完整到被掰开、酱汁从无到流淌、产品从画外到画内
4. **镜头切换**：中景切到特写、固定机位切到推镜、角度变化
5. **光影变化**：逆光转侧光、明暗对比变化

#### 时间轴标注格式

```
[00:00] 第1帧：{简短描述}
[00:30] 第2帧：{简短描述}（0.5秒后）
[01:00] 第3帧：{简短描述}（1秒后）
[01:30] 第4帧：{简短描述}
...
[14:30] 第30帧：{简短描述}（14.5秒后）
```

**注意**：时间码格式为 `[秒:毫秒百位]`，如 `[03:50]` = 3.5秒

#### 关键帧识别策略（按类型）

**沉浸式吃播**（聚焦食物动态和咀嚼细节）：
- 拿起食物（完整形态）
- 手指接触食物准备掰/撕
- 掰开/撕开瞬间
- 内馅暴露/酱汁开始流淌
- 酱汁流淌到最大量
- 食物靠近嘴边
- 咬下瞬间（牙齿接触）
- 咀嚼开始（腮帮鼓起）
- 咀嚼中段（眼睛闭上）
- 咀嚼享受（表情舒展）
- 吞咽瞬间
- 手伸向下一个

**口播类**（聚焦产品操作和讲解同步）：
- 痛点展示开始
- 产品出现
- 产品被拿起
- 产品展示正面
- 操作步骤1开始
- 操作步骤1关键动作
- 操作步骤2开始
- 效果展示
- 对比前后
- 收尾引流

**剧情类**（聚焦表情冲突和对话瞬间）：
- 冲突开场第一句话说出口
- 对方反应（表情变化）
- 肢体动作（指向/后退/转身）
- 产品被否定瞬间
- 反转前的停顿
- 反转瞬间（表情180度转变）
- 打脸表情
- 围观者反应
- 产品被正名
- 情感升华

### Step 3：逐帧四维度描述

对识别出的每一帧，进行**精简版四维度描述**：

```
[时间码], {镜头语言}
动作：{核心动作+产品状态}
情绪：{表情+眼神}
环境：{关键变化}
(音效：{主要音效})
```

**与创作线四层描述的区别**：
- 创作线：完整详细，每层2-3句话
- 反推线：精简核心，每层1句话

#### 帧级描述示例（沉浸式吃播）

```
[00:00], {半身中景/固定机位/景深f/8}
动作：右手从塑料袋拿出热包子举至胸前，双手捏两端，热气冒起
情绪：眼神低垂看包子，眉毛微挑期待
环境：车内座椅清晰，车窗外招牌可见
(音效：塑料袋沙沙+轻微吸口水)

[00:50], {特写/固定机位/景深f/2.8}
动作：双手开始掰开包子，断口刚出现
情绪：眼神盯断口，喉结微动
环境：背景虚化，焦点在包子
(音效：包子皮撕开声)

[01:00], {特写/固定机位/景深f/2.8}
动作：包子掰开至一半，酱汁开始涌出
情绪：眼睛微睁大，嘴唇微张
环境：酱汁反光清晰
(音效：酱汁流动声+吸口水声明显)

[01:50], {特写/固定机位/景深f/2.8}
动作：包子完全掰开，酱汁流淌至最大量滴落
情绪：眼神紧盯酱汁，吞咽动作
环境：热气猛烈升腾
(音效：酱汁滴落塑料袋+热气嘶嘶)

[02:50], {大特写/固定机位}
动作：包子靠近嘴边，距离5cm
情绪：嘴唇微张准备咬
环境：焦点在嘴和包子
(音效：呼吸声)

[03:00], {大特写/固定机位}
动作：牙齿接触包子，开始咬下
情绪：眼睛开始闭
环境：咬合瞬间清晰
(音效：咬合声)

[03:50], {大特写/固定机位}
动作：大口咬下，酱汁挤出沾嘴唇
情绪：眼睛完全闭上
环境：嘴唇油光
(音效：咀嚼声开始)

[04:50], {大特写/固定机位}
动作：腮帮子鼓起咀嚼中
情绪：眉头微皱（被味道击中）
环境：腮帮鼓动清晰
(音效：咀嚼湿润声+满足"嗯")
```

### Step 4：类型适配过滤

根据Step 1识别的类型，对每帧描述进行权重调整：

#### 沉浸式吃播
- **强化**：动作层（食物细节）、音效层（三件套）
- **简化**：环境层（重复的背景可省略）
- **跳过**：无台词

#### 口播类
- **强化**：动作层（操作步骤）、台词同步
- **简化**：情绪层（口播表情变化较少）
- **保留**：台词逐字对应时间轴

#### 剧情类
- **强化**：情绪层（表情冲突）、台词对白
- **保留**：所有维度均重要

### Step 5：组装输出格式

#### 帧级复刻输出结构

```
## 视频信息
- 类型：{沉浸式吃播/口播/剧情}
- 时长：15秒
- 总帧数：30帧（一秒2帧密度）
- 核心特征：{3-5个关键词}

## 头部信息块
{按v2.0格式输出完整头部}

## 30帧时间轴（帧级复刻）

[00:00] 第1帧：{一句话概括}
{四维度精简描述}

[00:50] 第2帧：{一句话概括}
{四维度精简描述}

...（30帧全部列出）

[14:50] 第30帧：{一句话概括}
{四维度精简描述}

## 即梦提示词（合并版）

{将30帧合并为5-7个分镜的标准提示词，供即梦生成使用}
```

### Step 6：质量自检

**帧级复刻检查清单**：
- [ ] 30帧时间轴完整（0.5秒间隔）
- [ ] 每帧四维度描述完整
- [ ] 关键动作瞬间没有遗漏（掰开/咬下/流淌/表情转折）
- [ ] 时间码格式正确 `[秒:毫秒百位]`
- [ ] 音效在关键帧标注完整
- [ ] 头部信息块符合v2.0格式
- [ ] 提供了合并版提示词供即梦使用

## 分镜级反推流程（快速模式）

当用户需要快速理解视频结构时，使用分镜级反推（2-3秒/分镜）。

### Step 1：视频类型识别
（同帧级反推Step 1）

### Step 2：分镜切分（5-7个分镜）

按照镜头切换、动作完成、情绪转折等自然节点切分。

### Step 3：6维度拆解

对视频内容进行6个维度的完整拆解：

#### ① 人物与产品（核心要素）
- 博主类型：（服装/美食/美妆/母婴/宠物/家居/数码/健身）
- 人物性别：（仅在需要区分男女装时标注，其余不描述外貌）
- 产品类型：（服装/食品/护肤品/电子产品等）
- 人物与产品的交互关系：（手持/穿戴/食用/展示/递向镜头/掰开/撕开/咬下）
- 口播台词：（有/无，有则逐字记录）
- 音色：（有/无）

#### ② 镜头与运镜
- 画幅比例：竖屏9:16（带货类默认）
- 每个分镜景别：远景/中景/近景/特写/微距/大特写
- 每个分镜角度：正面平视/侧面/俯拍/仰拍/过肩
- 每个分镜运镜：固定机位/推镜/拉远/跟拍/环绕/硬切
- 分镜切换方式：硬切/卡点切/慢动作/溶解/一镜到底
- 每个分镜时长：精确到秒

### Step 3：6维度拆解

对每个分镜进行完整的6维度拆解：

#### ① 人物与产品（核心要素）
- 博主类型：（服装/美食/美妆/母婴/宠物/家居/数码/健身）
- 人物性别：（仅在需要区分男女装时标注，其余不描述外貌）
- 产品类型：（服装/食品/护肤品/电子产品等）
- 人物与产品的交互关系：（手持/穿戴/食用/展示/递向镜头/掰开/撕开/咬下）
- 口播台词：（有/无，有则逐字记录）
- 音色：（有/无）

#### ② 镜头与运镜
- 画幅比例：竖屏9:16（带货类默认）
- 每个分镜景别：远景/全景/中景/半身中景/近景/特写/大特写
- 每个分镜角度：正面平视/侧面/俯拍/仰拍/过肩
- 每个分镜运镜：固定机位/推镜/拉镜/跟镜/横摇/竖摇/环绕
- 每个分镜景深：f/1.4/f/2.8/f/5.6/f/8（浅景深到深景深）
- 分镜切换方式：硬切/卡点切/溶解/淡入淡出
- 每个分镜时长：精确到秒

#### ③ 动作与表情
- 模特核心动作：（手持展示/揉搓面料/穿上身/递向镜头/咀嚼/涂抹/掰开/撕开）
- 动作拆解六维度：身体部位/起点→终点/速度/力度/空间位置/附加动作
- 表情状态：（自信冷漠/温柔满足/惊喜真诚/高冷微笑/慵懒陶醉/沉浸享受）
- 表情变化弧光：（从期待→满足→享受→停不下来）
- 肢体语言：（叉腰/双手摊开/插兜/双手捧起/扭腰转身）
- 眼神方向：（直视镜头/侧看/微微低垂/看食物/闭眼品味/眼神在产品和镜头间移动）
- 微表情细节：（眉毛挑起/舒展/皱起，嘴角上扬/抿紧，喉结滚动）

#### ④ 环境与场景
- 室内/室外/车内
- 具体场景：（广告棚/家居客厅/厨房/户外公路/卧室/豪车后座/街边店铺门口/阳台）
- 光源方向：（正面柔光/侧光45度/逆光/顶光/底光）
- 光质：（柔光/硬光）
- 光效描述：（高光位置/阴影层次/轮廓光/眼神光）
- 背景景深：（深景深f/8全部清晰/浅景深f/2.8虚化）
- 环境细节：（品牌logo/招牌/路人/蒸笼热气/霓虹灯/真皮座椅纹理等）

#### ⑤ 画面风格与色调
- 整体风格：（写实真人风格/电影质感/iPhone原相机感/纪录片感）
- 色调倾向：（暖黄高饱和/冷白高级/冷灰莫兰迪/清透冷绿/暖粉柔光/暖白自然光）
- 画质：（8K超高清/真实手机拍摄感）
- 整体氛围：（高冷克制/治愈温馨/慵懒精致/沉浸ASMR/反差感/烟火气）

#### ⑥ 细节与音效
- 材质细节：（面料纹理/食物油光/皮质光泽/金属反光/液体粘稠度/酱汁拉丝）
- 动态细节：（面料飘动/发丝颤动/蒸汽升起/泡沫爆发/酱汁流淌/汁水喷溅）
- 音效三层结构：
  - [环境层] 场景环境音
  - [动作层] 主要动作音效
  - [情绪层] 人物情绪音效

### Step 4：类型适配过滤

根据视频类型调整维度权重：

#### 沉浸式吃播
- **强化**：③动作与表情（咀嚼细节、食欲表情）、⑥音效（三件套必备）、④场景（生活化细节）
- **弱化**：②运镜（通常固定机位为主）
- **跳过**：台词、音色

#### 沉浸式非食品（服装展示）
- **强化**：③动作（面料动态、自然小动作）、④场景（背景稳定性）、⑤色调风格
- **弱化**：⑥音效（环境音即可）
- **跳过**：台词、音色

#### 口播功能演示
- **强化**：①人物与产品交互（操作步骤）、④场景（产品使用的真实场景）、台词逐字记录
- **弱化**：⑤色调（通常自然光即可）
- **保留全部**：台词、音色

#### 口播种草推荐
- **强化**：③表情（被产品打动的真实反应）、台词（情绪递进结构）
- **弱化**：②运镜（通常简单机位）
- **保留全部**：台词、音色

#### 剧情类
- **强化**：全部维度均重要，尤其②运镜（剧情需要镜头语言叙事）、③情绪（冲突/反转/打脸）、台词/对白
- **特殊**：需额外拆解剧情结构（冲突→升级→反转→产品揭示）

### Step 6：精简检查

- 【】只用于即梦素材槽位（【人物】【产品】【背景】【音色】）
- 人物外貌默认不描述（通过【人物】槽位给照片）
- 产品外观默认不描述（通过【产品】槽位给照片）
- 每条分镜四层描述清晰
- 台词精简自然，不堆砌
- 音效分三层标注
- 总字数控制在2000字符以内
- 时间码使用方括号 `[]`

## 反推输出的质量标准

反推出的提示词应该能让即梦生成出"和原视频高度相似"的新视频。

### 帧级复刻质量标准

1. **时间轴完整度**：30帧全覆盖，无遗漏
2. **关键瞬间捕捉**：动作变化/表情转折/产品状态变化的瞬间必须有独立帧
3. **描述精确度**：每帧四维度描述精准，不模糊不抽象
4. **音效同步度**：关键音效与画面帧精确对应
5. **可执行性**：后续Codex可从30帧中精选关键帧用于即梦生成

### 分镜级复刻质量标准

1. **场景还原度**：背景环境、光线、色调是否与原视频一致
2. **动作还原度**：核心动作、表情、眼神方向是否匹配
3. **节奏还原度**：分镜时长、切换方式是否与原视频节奏一致
4. **氛围还原度**：整体感觉是否与原视频调性一致
5. **格式合规性**：是否符合L1铁律和v2.0电影级格式规范

## 两种模式对比总结

| 维度 | 帧级复刻 | 分镜级复刻 |
|---|---|---|
| 时间粒度 | 0.5秒/帧 | 2-3秒/分镜 |
| 总数量 | 15秒=30帧 | 15秒=5-7分镜 |
| 描述详细度 | 精简版四维度（1句/维度） | 完整版四层描述（2-3句/层） |
| 适用场景 | 精确复刻、秒级还原 | 快速理解、结构分析 |
| 输出字数 | 3000-5000字符 | 1500-2000字符 |
| 后续流程 | 配合Codex提取关键帧截图 | 直接用于即梦生成 |

**默认选择**：用户说"反推/复刻/拆解" → **帧级复刻**（精确度优先）
