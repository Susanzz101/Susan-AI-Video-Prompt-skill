# 统一输出格式规范

本文档规定即梦视频提示词的输出格式标准，确保所有类型的提示词格式统一、专业、可执行。

---

## 一、核心原则

### 1.1 四层描述结构
每个分镜必须包含以下四层，且**按顺序独立成行/段**：

```
[时间码], {镜头语言层}
动作描述层（人物主要动作+产品状态）
情绪描述层（表情/眼神/情绪变化）
环境/光影层（场景细节/光影效果）
(音效：音效设计层)
```

**层级关系**：
- **镜头语言层**：告诉即梦"用什么视角拍"
- **动作描述层**：告诉即梦"发生了什么"
- **情绪描述层**：告诉即梦"人物感受如何"
- **环境/光影层**：告诉即梦"画面质感如何"
- **音效设计层**：告诉即梦"听到什么声音"

### 1.2 秒级精确时间码
- 使用**方括号** `[]` 而非圆括号
- 粒度：**2-3秒**为一个分镜（15秒视频拆分为5-7个分镜）
- 格式：`[00:00-00:03]` 或 `[00:03-00:05]`

### 1.3 符号系统规范

| 符号 | 用途 | 示例 |
|---|---|---|
| `[]` | 时间码 | `[00:00-00:03]` |
| `{}` | 镜头语言（景别/运镜/景深/构图） | `{特写/缓推/景深f/2.8}` |
| `【】` | 即梦素材槽位 | `【人物】【产品】【背景】【音色】` |
| `()` | 补充说明/策略标注 | `(黄金3秒钩子)` `(卖点可视化)` |
| `「」` | 台词内容 | `口播台词：「这个真的好用」` |

## 二、提示词完整结构模板

### 2.1 头部信息块（必备）

```
【视觉风格】写实真人风格，8K超高清，竖屏9:16。
【台词音色】中文台词无字幕，用这个音色【音色】。（若无台词则写"无台词无字幕"）
【音乐音效】无背景音乐，有环境音效和动作音效。（或根据类型调整）
【色调光影】{色调描述}，{光源描述}。
【拍摄质感】iPhone原相机真实拍摄感 / 电影质感 / 纪录片质感（根据需求选择）

【人物设定】【人物】{人物状态描述，如服装/发型/妆容/情绪状态}。（多人则分行描述）
【场景环境】{场景类型+具体细节描述}。若使用【背景】槽位则只描述人物与背景的位置关系。
【产品设定】【产品】{产品在画面中的初始状态}。

【整体氛围】{氛围关键词+情绪调性}。
```

**头部信息块示例**（沉浸式吃播）：
```
写实真人风格，8K超高清，竖屏9:16。无字幕无台词无背景音乐。暖黄高饱和色调，午后自然光从车窗侧面照入。iPhone原相机真实拍摄感。

【人物】长发披肩，白色T恤，坐在车内后座。
【场景】劳斯莱斯后座，米色真皮座椅+车顶星空灯+车窗外夜市街景清晰可见，深景深f/8全部清晰入镜。
【产品】酱肉包子装在白色塑料袋中放在腿上，热气从袋口冒出。

整体氛围豪车配市井美食的反差感，沉浸ASMR。
```

### 2.2 分镜描述块（核心）

**标准格式**：
```
[时间码], {镜头语言}
动作描述：主体+动作拆解（六维度）+产品状态变化。
情绪描述：表情变化+眼神移动+情绪词。
环境/光影：画面中的环境细节/光影效果/氛围营造。
(音效：[环境层] + [动作层] + [情绪层])
```

**完整示例**：
```
[00:00-00:03], {半身中景/固定机位/景深f/8}
模特右手从白色塑料袋中拿出一个热包子，双手捏住两端，热气从手指缝往上冒。
眼神自然低垂看着手中的包子，嘴唇微张像在期待第一口，眉毛微微上挑。
车内真皮座椅的米色清晰可见，车顶星空灯点点光斑，车窗外夜市招牌霓虹闪烁。
(音效：[环境层]车内密闭空间底噪+车窗外隐约人声 [动作层]塑料袋沙沙声+包子拿起的柔软触感声 [情绪层]轻微吸口水声)

[00:03-00:06], {特写/缓推2秒/景深f/2.8}
双手缓缓掰开包子，酱色肉馅从断口处涌出，浓稠酱汁顺着包子皮往下淌，热气从内馅猛烈升腾。
眼神紧盯着掰开处流淌的酱汁，眼睛微微睁大，嘴角不自觉咽口水。
背景虚化成暖黄光斑，焦点全在包子断口的酱汁流淌细节上。
(音效：[动作层]包子皮撕开柔软声+酱汁流动湿润声+热气升腾细微嘶嘶声 [情绪层]明显的吸口水声)
```

## 三、分镜数量与时间分配标准

### 3.1 单段15秒视频

**推荐分镜数**：5-7个分镜
**时间分配**：2-3秒/分镜

**分配逻辑**：
- **开场镜头**（第1个）：3秒（建立场景+钩子）
- **中间镜头**（第2-5个）：2-3秒（动作展开+细节特写）
- **收尾镜头**（最后1个）：2-3秒（情绪高潮+引导行动）

**时间分配示例**：
```
15秒 = [0-3] + [3-5] + [5-8] + [8-11] + [11-13] + [13-15]
       3秒    2秒     3秒     3秒      2秒       2秒
       开场   推进   高潮   延续     转折      收尾
```

### 3.2 多段视频（30秒/60秒）

**30秒 = 2段×15秒**
- 第一段：建立+铺垫（0-15秒）
- 第二段：高潮+转化（15-30秒）

**60秒 = 4段×15秒**
- 第一段：钩子开场（0-15秒）
- 第二段：问题展开（15-30秒）
- 第三段：解决方案（30-45秒）
- 第四段：行动号召（45-60秒）

**多段衔接规则**：参考 `creation/multi_segment/continuity_rules.md`

## 四、四层描述的详细规范

### 4.1 动作描述层

**必须包含的元素**：
1. **主体**：谁在做动作（模特/手/双手/右手食指）
2. **动作拆解**：参考六维度（起点→终点/速度/力度/位置/附加动作）
3. **产品状态**：产品在这个动作中的变化

**错误示例**：
❌ `模特拿起产品展示。`（太笼统）

**正确示例**：
✅ `模特右手从画面下方缓缓托起【产品】至胸前位置，手指轻握瓶身中部避开标签区，停顿0.5秒后轻轻旋转瓶身使正面标签完全对准镜头。【产品】在手中占据画面中心40%，瓶身在侧光下有明显高光。`

**动作描述公式**：
```
{主体} + {从哪里}→{到哪里} + {怎么动} + {速度} + {力度} + {附加动作}
+ 【产品】在这个动作中的{位置/角度/状态}变化
```

### 4.2 情绪描述层

**必须包含的元素**：
1. **眼神**：看向哪里+眼神移动轨迹
2. **表情**：眉毛/嘴角/脸颊的变化
3. **情绪词**：期待/满足/惊喜/真诚/陶醉等

**错误示例**：
❌ `模特很开心。`（太抽象）

**正确示例**：
✅ `眼神从低垂看产品缓缓抬起看向镜头，眉眼间从好奇转为确认，最后嘴角带出"就是它"的微笑，整个表情是真诚推荐的自然状态。`

**情绪描述公式**：
```
眼神{从哪到哪/看什么} + 眉毛{挑起/舒展/微皱} + 嘴角{上扬/微笑/抿紧}
+ 整体情绪词{期待/满足/惊喜/享受}
```

**情绪弧光**（15秒内的变化）：
- 沉浸式吃播：期待→满足→享受→停不下来
- 口播种草：真诚→专注→惊喜→分享满足
- 剧情类：冲突→转折→恍然大悟→爽感

### 4.3 环境/光影层

**必须包含的元素**（二选一或组合）：
1. **环境细节**：背景中的具体物体/陈设/人物（深景深时）
2. **光影效果**：光位/光质/高光/阴影/氛围（浅景深时）

**环境细节描述**（深景深时）：
✅ `车内米色真皮座椅纹理清晰，车顶星空灯点点光斑，车窗外夜市招牌"老北京包子铺"五个红字霓虹闪烁，路人和电瓶车经过。`

**光影效果描述**（浅景深时）：
✅ `背景虚化成暖黄光斑，左侧45度柔光照射，鼻梁有清晰高光，右脸颊有柔和阴影过渡，眼睛有明显眼神光。`

**组合描述**（环境+光影）：
✅ `咖啡厅暖光灯从顶部柔和照下，吧台后方咖啡机和木质货架清晰可见，空气中有轻微的咖啡香氛氛围（虽然即梦无法生成气味但可描述氛围感）。`

### 4.4 音效设计层

**三层结构**（必须分层标注）：
```
(音效：
  [环境底噪层] {场景环境音}
  [动作音效层] {主要动作产生的声音}
  [情绪音效层] {人物情绪相关声音}
)
```

**示例**：
```
(音效：
  [环境层] 车内密闭空间底噪+车窗外隐约街市声+电瓶车按喇叭声远处
  [动作层] 包子皮撕开柔软声+酱汁流动湿润声+咬合咀嚼声+吞咽声
  [情绪层] 轻微吸口水声+满足的"嗯——"轻哼声+呼吸声加重
)
```

**音效密度**：
- 沉浸式吃播：音效最密集（ASMR核心）
- 口播类：音效适中（环境底噪+产品操作音）
- 剧情类：音效分幕设计（第一二幕环境音为主，第三四幕加BGM）

## 五、不同类型的格式适配

### 5.1 沉浸式吃播（无台词）

**头部信息块特征**：
- ✅ 无字幕无台词无背景音乐
- ✅ 深景深f/8（展示环境细节）
- ✅ 固定机位为主
- ✅ 暖黄/暖白色调（食物适配色调）

**分镜描述特征**：
- 动作层：聚焦"撕/掰/咬/咀嚼"等食物专属动作
- 情绪层：眼神自然下垂看食物（非直视镜头），闭眼享受
- 环境层：必须详细描述场景（车内座椅/街边店铺）
- 音效层：**音效三件套**必备（咀嚼+吸口水+嗯声）

**时间分配**：
```
[0-3]：拿起食物+展示完整形态
[3-6]：关键动作A（撕开/掰开）
[6-9]：关键动作B（咬下咀嚼）
[9-12]：关键动作A重复（继续撕/掰）
[12-15]：收尾定式（满足咀嚼+手伸向下一个）
```

### 5.2 口播类（有台词）

**头部信息块特征**：
- ✅ 中文台词无字幕，用这个音色【音色】
- ✅ 浅景深f/2.8（虚化背景突出人物）
- ✅ 固定机位+偶尔缓推
- ✅ 自然光/柔光（舒适真实）

**分镜描述特征**：
- 动作层：产品展示+功能演示
- 情绪层：眼神在镜头和产品间切换，表情真诚
- 环境层：浅景深时写光影，深景深时写环境
- 音效层：环境底噪+产品操作音+人物声音（呼吸/语调）

**台词标注格式**：
```
口播台词：「这个真的太好用了，我用了三个月。」
```

**时间分配**：
```
[0-3]：痛点钩子/身份钩子开场
[3-6]：产品引入+展示
[6-10]：功能演示/卖点展示
[10-15]：效果总结+轻度引流
```

### 5.3 剧情类（有对白）

**头部信息块特征**：
- ✅ 多人物分行描述
- ✅ 场景可风格化（不限于生活化）
- ✅ 运镜丰富（推拉摇移组合）
- ✅ BGM分幕设计

**分镜描述特征**：
- 动作层：对话中的肢体动作+产品植入动作
- 情绪层：情绪冲突→转折→爽感的弧光
- 环境层：营造剧情氛围（海边/超市/办公室）
- 音效层：环境音+动作音+情绪音效（心跳/吞咽）

**四幕结构**：
- 第一幕（0-15s）：冲突开场，产品被忽视
- 第二幕（15-30s）：对比反转，产品效果证明
- 第三幕（30-45s）：情感高潮，产品被追问
- 第四幕（45-60s）：产品展示+转化

## 六、质量自检清单

生成提示词后，必须通过以下检查：

### 6.1 格式检查
- [ ] 时间码使用方括号 `[]` 而非圆括号
- [ ] 时间粒度为2-3秒/分镜
- [ ] 每个分镜包含四层（镜头/动作/情绪/环境/音效）
- [ ] 镜头语言用 `{}`，素材槽位用 `【】`
- [ ] 音效分层标注 `[环境层] [动作层] [情绪层]`

### 6.2 内容检查
- [ ] 字符数在2000以内
- [ ] 无跨段引用词（维持/延续/上一段等）
- [ ] 动作描述精确（六维度）
- [ ] 情绪描述有弧光（不是平面的）
- [ ] 产品每镜都有状态追踪
- [ ] 音效三件套齐全（针对沉浸式吃播）

### 6.3 专业度检查
- [ ] 镜头语言使用电影级术语（推拉摇移/景深/光影）
- [ ] 动作拆解到位（不用"拿起""展示"等笼统词）
- [ ] 色调匹配食物/产品类型
- [ ] 场景具体生活化（非"虚化背景"）
- [ ] 收尾符合类型定式

## 七、输出流程

### Step 1：识别类型和需求
- 沉浸式/口播/剧情？
- 单段15秒还是多段？
- 食物类型/产品类型是什么？
- 场景在哪里？

### Step 2：组装头部信息块
根据类型填充头部模板（视觉风格/台词音色/场景/人物/产品）

### Step 3：设计分镜节奏
- 确定分镜数量（5-7个）
- 分配时间（2-3秒/分镜）
- 设计情绪弧光
- 规划产品线

### Step 4：逐镜填充四层描述
按照 `[时间码], {镜头语言}` + 动作层 + 情绪层 + 环境层 + 音效层 的格式逐个填充

### Step 5：质量自检
通过上述三大检查清单

### Step 6：输出最终提示词
以markdown格式输出，清晰分段

## 九、常见错误与纠正

### 错误1：时间码粒度过粗
❌ `(00:00-00:05)` 5秒一个分镜
✅ `[00:00-00:03]` 3秒或更短

### 错误2：动作描述笼统
❌ `模特展示产品`
✅ `模特右手从画面下方缓缓托起【产品】至胸前位置，手指轻握瓶身中部避开标签区`

### 错误3：情绪描述混在动作中
❌ `模特开心地拿起产品`
✅ 动作层：`模特双手捧起【产品】`
   情绪层：`嘴角带出真诚微笑，眉眼舒展，整个表情是分享的满足状态`

### 错误4：缺少环境层
❌ 只写了动作和情绪，没有环境/光影描述
✅ 必须补充：深景深写环境细节，浅景深写光影效果

### 错误5：音效平面罗列
❌ `(音效：撕开声+咀嚼声+吸口水声+车内声)`
✅ `(音效：[环境层]车内底噪 [动作层]撕开+咀嚼 [情绪层]吸口水)`

### 错误6：镜头语言单一
❌ 全是 `{半身中景/固定机位}`
✅ 组合使用 `{特写/缓推}` `{近景/跟镜}` `{俯拍/景深f/2.8}`

## 十、格式演进说明

### 当前版本：v2.0（电影级格式）
- 时间码：方括号 `[]` + 2-3秒粒度
- 描述结构：四层（镜头/动作/情绪/环境/音效）
- 镜头语言：电影级（推拉摇移+景深+光影）
- 音效设计：三层分类

### 向下兼容：v1.0（基础格式）
- 时间码：圆括号 `()` + 4秒粒度
- 描述结构：单段线性描述
- 镜头语言：基础景别
- 旧格式案例依然可用，但不推荐

### 使用建议
- **新创作**：统一使用v2.0电影级格式
- **旧案例**：逐步升级到v2.0格式
- **快速生成**：可临时使用简化版，但需标注"简化版"

## 十一、与其他文档的关系

本文档（output_format_standard.md）规定**怎么写**，配合以下文档：

- **cinematic_language.md**：提供镜头语言词库（**写什么术语**）
- **L1_iron_rules.md**：不可打破的平台限制（**不能写什么**）
- **L2_defaults.md**：各类型默认配置（**各类型的差异**）
- **各类型skill文档**：具体类型的规则（**该类型怎么写**）

**加载顺序**：
1. L1铁律（不可打破）
2. L2默认值（可覆盖）
3. output_format_standard（格式规范）
4. cinematic_language（镜头语言词库）
5. 具体类型skill（类型专属规则）

遇到冲突时，L1 > 类型skill > 格式规范 > L2默认值
